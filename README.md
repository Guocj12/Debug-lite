# Debug-Lite 霓虹像素格斗

16 格横版双人对战格斗游戏，支持人机对战、训练场、联机对战和技能编辑。

---

## 本地部署与运行

### 环境要求

- [Node.js](https://nodejs.org/) 18.x 或更高版本
- npm（随 Node.js 一并安装）

### 安装步骤

```bash
# 1. 进入项目目录
cd Debug-lite

# 2. 安装依赖
npm install

# 3. 启动服务器
npm start
```

启动后，在浏览器中打开 **http://localhost:3456** 即可开始游戏。

## 如何游玩

### 选择模式

进入游戏后，主菜单提供四种模式：

| 模式 | 说明 |
|------|------|
| ⚔️ **人机对战** | 与 AI 对手进行 1v1 对战 |
| 🎯 **训练场** | 自由练习，无对手压力 |
| 🌐 **联机对战** | 与另一位玩家通过房间号联机对战 |
| 📝 **技能编辑** | 自定义技能配置 |

### 选择角色与技能

1. 选择一个角色：**战士**（均衡近战）、**射手**（远程弹幕）、**法师**（范围法术）、**刺客**（高机动背刺）
2. 从该角色的技能池中挑选 **3 个技能** 带入对战

### 联机对战流程

1. **创建房间**：输入昵称，点击"创建"，将生成的房间号发送给朋友
2. **加入房间**：朋友输入房间号，点击"加入"
3. 双方选择角色和技能后开始对战

### 战斗操作

每回合分为两个阶段：

#### 📋 编辑阶段（准备阶段）

在行动队列面板中编排本回合的 16 个行动格。每一格可选择一个技能或普通攻击：

- 点击技能按钮将其加入行动队列
- 点击 **清空** 重置队列
- 点击 **撤销** 移除最后添加的行动
- 编排完成后点击 **✅ 完成** 提交

#### ⚡ 战斗阶段

双方的行动队列同时逐格执行，系统自动计算伤害、命中与 Buff 效果。观察动画回放，看谁的策略更胜一筹。

### 资源系统

- **HP（生命值）**：归零则本回合落败
- **MP（法力值）**：释放技能消耗
- **SP（体力值）**：部分技能与行动消耗

合理分配技能消耗、预判对手行动是取胜关键。

### 胜利条件

对战持续多个回合，先耗尽对方 HP **或摧毁对方基地** 的一方获胜。基地位于地图两端（格0和格15），需移动到对手基地位置造成碰撞伤害（基地ATK=0不会反击）。若回合数达到上限则以剩余 HP 多的一方为胜。击杀对手后攻击基地是迟早的事。

## AI 训练

游戏内置了一个基于**遗传算法 + 蒙特卡洛模拟**的 AI 训练脚本，可以让 AI 学会智能对战（替代默认的纯随机行动）。

### 原理

- **遗传算法**：模拟自然选择 —— 随机生成一批"策略个体" → 每代互相对战评估胜率 → 精英保留 → 交叉繁殖 → 随机变异 → 重复迭代
- **蒙特卡洛模拟**：每个策略个体打 200 场随机对手，用胜率估计其真实强度

### 训练命令

```bash
# 训练全部 4 个角色（推荐）
node server/train-ai.js --gens 50 --pop 100

# 只训练一个角色
node server/train-ai.js --gens 50 --pop 100 --char warrior

# 快速验证（低精度，仅用于测试脚本是否正常）
node server/train-ai.js --quick --gens 10 --pop 20
```

### 参数说明

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `--gens` | 100 | 遗传算法迭代代数，40~100 代通常足够收敛 |
| `--pop` | 60 | 每代种群大小（个体数），越大探索越充分但更慢 |
| `--char` | 全部 | 指定训练角色：`warrior` / `archer` / `mage` / `assassin` |
| `--quick` | false | 快速模式（每体仅评估 10 场，误差大，仅用于验证） |
| `--matches` | 200 | 每个个体的蒙特卡洛评估场次（越大越精确） |

### 训练产物

训练完成后会生成两个文件：

- `data/ai-weights.json` — 完整权重（供服务端读取）
- `data/ai-templates.json` — 简洁行动模板（人类可读）

启动 `npm start` 后服务端会自动加载权重。如果文件不存在则回退到随机 AI。

### 推荐配置

| 场景 | 命令 | 预估耗时 |
|------|------|---------|
| 日常训练 | `--gens 50 --pop 100` | 2~4 分钟 |
| 深度训练 | `--gens 100 --pop 200` | 5~10 分钟 |
| 快速验证 | `--quick --gens 10 --pop 20` | 5~10 秒 |
