# 关于本项目

纯vibe生成的pvp编程战斗游戏。
开箱获取角色，技能，插件，定制自定义角色，编写战斗ai，与随机匹配的对手对战。

# 技术栈

nodejs+前端三件套

# 游戏特色

编程自动对战
模块化组装角色/技能
开箱，刷词条，快节奏对局

# 以下为具体游戏设计

```
物品
一切模板和插件

    模板
    角色模板和技能模板
    有基础属性和多种插槽

    插件
    角色插件和技能插件
    有多种词条

    品质
    绿，蓝，紫，橙，青
    品质影响物品属性及词条数值的随机区间
    品质越高数值上限与下限越高

    获取
    开箱随机获取
    其他途径掉落等

    角色
    角色模板+角色插件得到的可参与战斗的实体

        角色基本属性
        hp，atk，def，sp，mp，每回合hp，每回合sp，每回合mp，由角色模板和角色插件词条计算得到的最终值

        角色特殊属性
        闪避率，暴击率，暴击伤害，由角色插件特殊词条提供

        角色战斗属性
        基本属性和特殊属性，战斗中可能由于各种原因变化的值
        maxhp，maxsp，maxmp，战斗中不变的值
        位置，0-15

        角色模板

            属性
            hp，atk，def，sp，mp

            类型
            均衡（标准属性范围）
            特化（1属性略高而1属性略低，其余均衡）
            专家（1属性极高，1属性略高，1属性极低，1属性略低，1属性均衡）
            
            插槽
            五维插槽，通用插槽，特殊插槽
            插槽数，种类随机且数量随品质递增

        角色插件

            类型
            五维插件（百分比/数值），只能插到对应或通用插槽
            特殊插件 闪避率，暴击率，暴击伤害，只能插到特殊插槽

            词条
            具体数值，由品质随机

    技能
    技能模板+技能插槽得到的战斗中可释放的行动
    每个角色可以装配三个技能

        技能基本属性
        倍率，消耗，冷却时间，弹幕等级

        技能特殊属性
        暴击率，暴击伤害，命中为敌人施加效果，释放时为自身施加效果

        技能模板及模板专有属性

            近战
            在攻击范围内每一格创建静止的弹幕
            范围 相对角色描述，0，2表示角色所在格及前方两格，-1，1表示角色所在格及前后各一格

            平射
            以角色所在格为起点，发射向前运动的弹幕
            射程 弹幕运动的路径长度，2表示运动到角色前方两格后消失
            弹幕数量 同时发射多少弹幕。每个弹幕之间独立计算命中。

            定点
            以对方角色所在格为目标格，在范围内每一格创建静止的弹幕
            射程 可释放的最远距离。若角色前方射程覆盖范围内不存在敌人则在最远端释放
            范围 相对落点描述，0，2表示落点所在格及前方两格，-1，1表示落点所在格及前后各一格
            伤害衰减 除落点外，离落点越远伤害越低

            位移
            角色移动，在路径上每一格创建静止的弹幕
            距离 角色移动的路径长度，2表示移动至前方两格
            是否穿过敌人 决定遇到敌人时停下还是越过
            是否造成伤害 决定是否在运动路径上创建弹幕
            完全闪避 决定本tick是否参与弹幕命中判定

        技能插件

            类型
            专属插件 只能装在特定模板上，改变模板机制。一个模板只能装一个专属插件
            通用插件 增加数值减少能耗，或其他一般增幅

            词条
            具体数值，由品质随机
    
    弹幕
    每tick生成并结算，可造成伤害，附加效果，相互影响

        弹幕等级
        1-4，1最高
        高级弹幕和低级弹幕碰撞时，低级弹幕消失；同级弹幕相互抵消

        弹幕结算
        每个弹幕每tick都会完成结算。
        同格结算优先级 命中弹幕>命中角色>到达最大射程后消失

    效果
    每tick行动前优先结算的，附加在角色身上的效果

        持续时间
        按tick计算，每tick-1。本tick施加的buff下tick生效

        类型

            控制类效果
            强制修改角色本tick行动

            持续伤害类效果
            每tick对角色造成固定倍率伤害

            增益/减益类效果
            持续影响角色数值，直到效果消失

    AI编辑

        AI
        玩家编写的行为逻辑，一段json结构，服务端每个tick执行一次产出一个行动
        最外层是引擎自带的while(true)，跑完最后一行自动回到第一行继续

            AI库
            每个玩家自己的程序仓库

                条目
                名字，程序正文，状态，创建时间，更新时间

                状态
                正式 通过了校验，可以被出战配置选中
                草稿 校验没通过时先存为草稿，不能被出战配置选中

        编辑器

            列表态
            每条AI一行 名字，正式还是草稿，被哪个配置引用，更新时间
            每行两个按钮 打开，删除
            底部 新建AI，刷新，返回主界面

            编辑态

                程序结构
                缩进显示程序的层级关系
                每行右侧「选中」把光标移到该节点
                「那么」「否则」「循环体」是分支和循环体的标签，它们下面的行缩进一层
                「← 当前选中」标记你正在改的那一行

                当前节点
                选中哪一行，就在下面改那一行的内容
                文本框：变量名，函数名，读取项，常量
                按钮组：动作名，运算符，比较符，逻辑符，循环类型，值类型

                节点
                共16类

                    语句块
                    一串按顺序执行的语句

                    动作
                    本tick要做的行动，见下面的行动表

                    如果
                    条件成立走那么，不成立走否则，否则可以留空

                    随机
                    按概率选择分支
                    放在语句位置=概率分支，真的执行那么或否则
                    放在条件或数值位置=只按概率取真假，分支不执行

                    循环
                    计次：按次数循环，次数只在进入循环时算一次
                    条件：每轮开始前判断条件，成立就再走一轮

                    跳出循环
                    直接结束最近的一层循环，只能放在循环体内

                    函数定义
                    给一段代码起名字，本身不执行
                    没有参数也没有返回值，内部变量不影响外面
                    名字不能和别的函数重复

                    调用函数
                    执行同名的函数定义，可以先调用后定义

                    声明变量
                    只在该作用域里第一次生效，重复执行不会重置

                    赋值
                    改已有变量的值

                    读变量
                    读变量的值

                    读战场数据
                    读战场上的数值，见下面的可读数据表

                    常量
                    数字，文本，真或假

                    算术
                    加，减，乘，整除，没有取余

                    比较
                    大于，小于，大于等于，小于等于，等于，不等于

                    逻辑
                    并且，或者
                    并且左侧为假就不看右侧，或者左侧为真就不看右侧

                可读数据
                共49项，服务端白名单，手写也只能写这些

                    战场
                    当前tick，战场总宽度，格子宽度

                    自身与对手
                    血量，血量上限，法力，法力上限，体力，体力上限
                    攻击，防御，位置，朝向，基地当前血量
                    技能1到3的剩余冷却，第1个效果的剩余帧数与内容

                    基地
                    我方和敌方基地的血量，血量上限，防御

                行动表
                共10个

                    右移，左移，向右闪避，向左闪避，防御，转身，等待
                    释放技能1，释放技能2，释放技能3

                校验
                改一下就自动校验一次
                结论只由服务端给，界面不自己判断对错
                校验通过才给保存，不通过只能存草稿
                出错会逐条列出来，每条带「定位」跳到出错的节点

                    判错逻辑
                    循环体里的每个分支都必须能产出一个动作
                    读变量，赋值，调用函数的名字必须先出现过
                    表达式的位置只能放表达式节点，不能放动作和语句
                    随机的否则是必填
                    函数名不能重复
                    程序上限：节点2000个，深度32层，256KB

            保存与生效

                保存
                写进AI库成为正式条目，编号不变

                存为草稿
                校验没过也能先放着，之后回来改

                另存为新的AI
                复制成一条新的

                导入JSON
                粘一段别人的程序进来，会替换当前草稿，粘完照样要过校验

                生效
                出战配置里存的是程序的副本，不是引用
                所以改完AI要在出战配置里重新选一次才会生效
                也所以改AI不会改到以前的回放

    战斗
    一场在16格横版场地上进行的编程自动对战，双方各有一个角色和一个基地

        场地
        16格，每格64像素，总宽1024像素
        角色中心只能落在离两侧边界半格以内
        左方起始在格3，右方起始在格12，各自朝向对方
        基地在场地两端外侧，各100血、64防

        回合
        每tick双方同时走一整套固定流程
        整场硬上限64tick，到上限仍未分出胜负判平局

            结算顺序
            1 冷却减1，清掉本tick的临时标记
            2 结算身上的持续效果
            3 取双方本tick的行动
            4 非法行动一律当等待
            5 控制类效果改写本tick行动
            6 提交意图：技能在此扣资源、写冷却、生成弹幕
            7 落位与角色碰撞，转身在此生效
            8 弹幕解算：互撞，命中，清场
            9 伤害结算：弹幕命中，角色碰撞，撞基地
            10 资源恢复，每tick回血回蓝回体并封顶
            11 超时扣血
            12 判定胜负
            13 输出本tick的画面帧

        行动
        每个角色每tick产出一个行动，共10个

            左移右移 各移动一格
            左闪右闪 各位移两格，本tick闪避率额外加2成，可穿过敌人
            防御 本tick防御力乘1.6
            转身 反转朝向，不位移
            等待 什么都不做
            释放技能 三个技能槽各算一个行动，按槽位各自冷却

        碰撞
        双方都不带穿过敌人且落位后中心距不足1格时，在接触点停下
        双方各受对方一次攻击，倍率0.8，走完整伤害流程
        双方都可穿则各沿自己的方向再进一格
        只有一方可穿时，可穿方落在不可穿方前进方向前方一格

        撞基地
        朝自己面向的那一侧基地移动且意图越过边界时触发
        撞的人停在原地，对方基地掉血：自身攻击力乘0.8，再吃基地64防的减伤
        撞基地不暴击、不背击、不吸血

        伤害
        一次命中按固定顺序算完，前面任一步免伤就不再往下走

            位移全程免疫
            位移技能带全程闪避时，该角色本tick不吃伤害也不参与命中判定

            闪避
            受击方闪避率成立则完全免伤，闪避率上限100%

            减伤
            防御按 防御÷(防御+40) 抵消，防御行动期间防御先乘1.6
            真实伤害跳过这一步

            背击
            打中背面时乘1.5，定点与范围弹幕永不背击

            暴击
            暴击率成立时乘2，暴击伤害词条在2倍之上继续叠加
            暴击率上限100%

            取整
            以上全部相乘后只取整一次，最低1点

            吸血
            按吸血比例回血，不超自身血量上限

            附带效果
            伤害生效后再施加眩晕、击退、拉近、持续伤害

            荆棘
            受击方带荆棘时按攻击者攻击力的比例反弹真实伤害

        属性
        攻击力受低血加攻词条影响，自身血量低于一半时按比例提高
        吸血、闪避、暴击都按100%封顶
        技能冷却每tick减1，减到0才能再释放

        超时
        第48tick起每tick双方角色与双方基地同时掉血
        角色掉自身血量上限的6.25%，基地掉自身血量上限的6.25%

        胜负
        基地先破者判负，双方基地同tick破判平局
        基地都还在时角色先死判负，双方角色同tick死判平局
        到tick上限未判出胜负判平局

    段位与积分

        段位
        由品质表的品质顺序决定的五级序列，自低到高为绿、蓝、紫、橙、青

            门控
            段位门控开关当前为关闭状态
            关闭时所有功能与节点全部解锁，段位不参与任何校验与筛选
            段位树与各表的段位标注仍保留，作为进度与评分元数据
            排位晋升与段位奖励不受该开关影响

            晋升
            每轮批次打满10场后判定，胜场数严格大于6才升一段，即至少胜7场
            平局不计胜场，也不占用晋升场次
            整轮10场全部打满才结段位，存在缺场则不判晋升
            胜场不足阈值时原地不动

            最高段
            最高段位没有后继段位，胜场再多也不再晋升
            判定请求仍按普通结果返回，只是不晋升

            离线防守
            被抽到的一方只记防守战绩、被抽次数与防守红点
            被抽一方段位不变、积分不变，离线不会掉段
            仓库中没有降段逻辑，任何路径都不降段

        积分
        只由快速对战改动，排位对战不改积分

            起点与上下限
            0起步，新档案积分即为0
            上限3000，下限0，任一场的结果积分都被夹在该区间内

            公式
            先由双方分差反推期望胜率，分差每400分对应一个10倍胜率比

            系数
            取胜时用加分系数，其上界32、下界8，随自身积分升高而线性递减
            告负时用扣分系数，其下界32、上界64，随自身积分升高而线性递增

            单场变化
            胜为加分系数乘以超出期望的部分，负为扣分系数乘以期望胜率再取负
            平局用固定系数32乘以0.5再乘以期望胜率与50%之差，故强者平局扣分、弱者平局加分
            每场变化按半向上取整，负数先取绝对值再取整

            非零和
            双方各自按自己的积分与系数结算，两侧变化之和不恒为0
            高分段扣得比对手加得多，系统整体存在分数汇
            0分玩家告负时被下限截断，反而向系统注入分数
            因此全局积分之和不保证非正

            未生效的常数
            起点常数已登记为0，但没有任何计算读取它，属未生效

        匹配
        排位从同段位池抽对手，快速对战的候选池不按段位过滤

            积分窗口
            快速对战按积分分差成窗匹配，窗口自100起每轮加100，上界600
            同窗口内命中即止，各窗口用完仍无候选则返回无对手错误

            软冷却
            同一对手距上次交手不足4小时者权重压低，随时间线性回满
            刚交手权重为0，满4小时后权重为1，从未交手直接按1计
            候选永不被硬性拒绝，全员权重为0时在最久未交手的组内抽签
            批次内同一对手不重复

            缺口
            候选不足10个时只打实际可用场次，缺口数如实回报
            绝不注入占位对手凑满场次，缺口是本轮的正常结果

            池来源
            真实玩家档案构成候选池，索引按段位给出名单
            逐候选要求有可用的出战快照正文、未封禁、在池内、非自己
            装配引用的仓库镜像缺失时，已校验过的候选按基准面板退化对局，未校验的候选跳过

            调试开关
            仅在环境变量显式开启时注入调试用对手档案，默认关闭
            开启只影响可选候选，缺口口径不变，响应体不含相应字段

        每日上限与批次
        每日对战场次上限已登记为0，但无任何消费方，当前不限制场次

            一轮场次
            一轮排位一次打10场，可在1到10之间覆盖，越界回落10

            结算时机
            一轮内逐场先算完战斗，再一次性提交全部结算，同一参与玩家一轮只落盘一次
            结算在本次请求内同步完成，无异步队列
            单场无法成立时记无效场次并跳过，整轮不失败

            幂等
            批次标识由玩家与种子确定性派生，同一玩家同一种子重发即命中既有批次
            命中时回放既有逐场结果，不重复抽池、不重复结算、不重复晋升
            单场标识由批次、场序、战斗种子与双方快照内容派生，天然幂等

        排行榜
        两张榜共用一套查询与分页参数

            积分榜
            按积分降序，同分先比历史最高积分降序，再比最近更新时间升序，末位按公开标识稳定排序

            段位榜
            按段位由高到低，同段位内按最后一次段位变化时间升序，先到者在前
            该时间是最后一次段位变化时刻，升段与改档都会刷新，不是首次到达该段位的时间
            该时间缺失的老数据排在本段位末尾

            分页与范围
```
