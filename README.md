# Debug-Lite 霓虹像素格斗

16 格横版双人对战格斗游戏，支持人机对战、训练场、联机对战和技能编辑。

---

## 本地部署与运行

### 环境要求

- [Node.js](https://nodejs.org/) 18.x 或更高版本
- npm（随 Node.js 一并安装）

### 安装步骤

```bash
# 1. 进入项目目录
cd Debug-lite

# 2. 安装依赖
npm install

# 3. 启动服务器
npm start
```

启动后，在浏览器中打开 **http://localhost:3456** 即可开始游戏。

## 如何游玩

### 选择模式

进入游戏后，主菜单提供四种模式：

| 模式 | 说明 |
|------|------|
| ⚔️ **人机对战** | 与 AI 对手进行 1v1 对战 |
| 🎯 **训练场** | 自由练习，无对手压力 |
| 🌐 **联机对战** | 与另一位玩家通过房间号联机对战 |
| 📝 **技能编辑** | 自定义技能配置 |

### 选择角色与技能

1. 选择一个角色：**战士**（均衡近战）、**射手**（远程弹幕）、**法师**（范围法术）、**刺客**（高机动背刺）
2. 从该角色的技能池中挑选 **3 个技能** 带入对战

### 联机对战流程

1. **创建房间**：输入昵称，点击"创建"，将生成的房间号发送给朋友
2. **加入房间**：朋友输入房间号，点击"加入"
3. 双方选择角色和技能后开始对战

### 战斗操作

每回合分为两个阶段：

#### 📋 编辑阶段（准备阶段）

在行动队列面板中编排本回合的 16 个行动格。每一格可选择一个技能或普通攻击：

- 点击技能按钮将其加入行动队列
- 点击 **清空** 重置队列
- 点击 **撤销** 移除最后添加的行动
- 编排完成后点击 **✅ 完成** 提交

#### ⚡ 战斗阶段

双方的行动队列同时逐格执行，系统自动计算伤害、命中与 Buff 效果。观察动画回放，看谁的策略更胜一筹。

### 资源系统

- **HP（生命值）**：归零则本回合落败
- **MP（法力值）**：释放技能消耗
- **SP（体力值）**：部分技能与行动消耗

合理分配技能消耗、预判对手行动是取胜关键。

### 胜利条件

对战持续多个回合，先耗尽对方 HP 的一方获胜。若回合数达到上限则以剩余 HP 多的一方为胜。
