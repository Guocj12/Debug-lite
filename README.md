# 🎮 霓虹像素双人对战游戏 (Neon Pixel Duel)

> 基于浏览器的霓虹像素风双人对战游戏。通过房间号联机，采用"预设行动队列 → 自动战斗"的独特机制。纯点击操作，兼容手机与电脑。

---

## ✨ 特性

- 🕹️ **独特战斗机制**：预设行动队列，策略博弈而非手速
- 🎨 **霓虹像素风格**：Canvas 渲染，复古赛博朋克视觉
- 📱 **全平台兼容**：响应式设计，手机/电脑均可玩
- 🔗 **房间号联机**：4 位房间码，快速匹配好友
- ⚡ **轻量零依赖前端**：原生 HTML/CSS/JS，无需框架

---

## 🚀 快速开始

### 环境要求

- [Node.js](https://nodejs.org/) >= 16.x
- npm（随 Node.js 一起安装）

### 安装与运行

```bash
# 1. 克隆项目
git clone https://github.com/Guocj12/Debug-lite.git
cd Debug-lite

# 2. 安装依赖
cd server
npm install

# 3. 启动服务
node index.js
```

服务启动后，浏览器访问 `http://localhost:3000`

## 🎮 玩法说明

### 基本流程

```
大厅匹配 → 准备阶段(60s) → 自动战斗 → 胜负判定
                ↑                ↓
                └── 无人死亡 ←───┘
```

### 操作指南

1. **创建/加入房间**：输入 4 位房间号，与好友联机
2. **准备阶段**：从角色池中选择角色，编辑行动队列
3. **战斗阶段**：双方队列同时执行，观看战斗动画
4. **胜负判定**：一方全部角色阵亡则游戏结束

## 🛠️ 技术栈

| 层 | 技术 | 说明 |
|----|------|------|
| 前端 | 原生 HTML/CSS/JS + Canvas | 零依赖（除 socket.io-client CDN） |
| 后端 | Node.js + Express + Socket.IO | 轻量实时通信 |
| 数据 | JSON 文件 | 角色、技能、像素画配置 |
| 部署 | pm2 + Nginx | 守护进程 + 反向代理 |
