# 美术素材规格表（照着画就行）

> 生成命令：`node tools/layout/art-spec.js`（本文件自动生成，勿手改）
> 与[素材清单](assets-manifest.md)的分工：清单说"缺不缺"，本表说"**该怎么画**"。

## 0. 交付方式（先读）

| 项 | 约定 |
|---|---|
| 格式 | PNG（透明底）+ 少量 SVG（品质框/段位） |
| 交付 | 把 PNG 放进仓库根的 assets-inbox/，文件名 = 表里的「文件名」列，然后跑 npm run assets:apply（自动改名→转 WebP→缩放→落位） |
| 尺寸 | 表里的尺寸是界面上的 CSS 像素；出图建议按 **2 倍**（如 512×512 就出 1024×1024），脚本会自动缩放 |
| 命名 | **文件名必须和表里一致**（例 `role_bal.png`、`btn_warehouse.png`、`用户头像.png`）；改名脚本才能认出来 |

**画图规则**：

- 所有图都不要在图里写字（名字由界面渲染，写了会重影）
- 透明底：除背景外都要留 alpha 通道
- 安全区：四周留 8% 空白，避免被圆角/多边形裁掉
- 不规则多边形元素：**整张画满**即可，界面按多边形裁切
- 风格统一：光源统一从左上、描边统一 2px 深色外描边、饱和度别拉满

**本轮规模**：目录物（角色/技能/插件/节点/包/品质框/段位/背景）**126** 张；界面控件（含弹窗）**42** 张。共 168 张。

**形状速查**：角色=六边形盾牌；技能=菱形盘（主界面会再按不规则多边形裁切）；插件=圆角方牌；AI 节点=代码块；包=箱体；品质框=圆角矩形边框；段位=盾形徽章；界面按钮=按表的比例做圆角矩形（不规则的元素已标注多边形顶点）。
