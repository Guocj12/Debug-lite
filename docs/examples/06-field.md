## 4. 撞基地判定（D-61）

判定条件（两条同时满足）：
1. 角色**朝向**基地（P1 朝 +1 打 P2 基地；P2 朝 −1 打 P1 基地）；
2. 本次移动/位移的**意图目标位置**会越过 `[32, 992]` 边界。

| # | 角色 | 位置/朝向 | 意图 | 判定 | 结果 |
|---|---|---|---|---|---|
| F-30 | P1 | 992 / +1 | move_right（目标 1056） | 越过上界且朝基地 → **撞基地** | 停在 **992**；P2 基地 `12×0.8×0.384615 = 3.692` → **−3** |
| F-31 | P1 | 928 / +1 | move_right（目标 **992**） | 恰好到 992，**未越过** → 普通移动 | 移动到 **992** |
| F-32 | P1 | 992 / +1 | move_left（目标 928） | 朝向基地但**背离**移动 | 移动到 **928**（无基地伤害） |
| F-33 | P1 | 500 / +1 | move_right（目标 564） | 远未触及边界 | 普通移动 |
| F-34 | P2 | 32 / −1 | move_left（目标 −32） | 越过下界且朝基地 → **撞基地** | 停在 **32**；P1 基地 `19×0.8×0.384615 = 5.846` → **−5** |
| F-35 | P1 | 992 / +1 | 位移技「突进斩」（目标 1248） | 越过上界 → 撞基地 | 停在 **992**；基地伤害按 **`atk×0.8`**（⚠ U-3：不用技能倍率） |
| F-36 | 任意 | 任意 | **平射/垂直/近战弹幕**打到基地方向 | **弹幕对基地伤害恒为 0**（D-60） | 基地血量不变 |

**对比要点**：F-30（停在原地、造成伤害）与 F-31（正常移动到边界格）的区别，只在于**意图目标是否越界**；这是"移动攻击基地会停在原地"的精确含义。

## 5. 击退 / 拉近（受控位移）

| # | 情形 | 初始 | 结果 |
|---|---|---|---|
| F-40 | 击退到场内 | A=528，击退 −2 格（−128px） | A = **400** |
| F-41 | 击退越界 | A=64，击退 −2 格 | `clampX(−64)` = **32** |
| F-42 | 击退推向敌人（会重叠） | A=500、B=600（gap100），A 被击退 +128 → 目标 628 | 不得使 gap<64 → A 钳到 **536**（gap 64）；**并结算碰撞伤害**（**D-35**）：A 受 **12**、B 受 **7** |
| F-43 | 拉近 | A=500、B=600（gap100），A 被拉近 +1 格 → 目标 564 | 目标 gap 36 <64 → A 钳到 **536**；**同样结算碰撞伤害**（A 受 12、B 受 7） |
| F-44 | 眩晕（displacement = 0） | 任意 | 位置不变（原地不动） |
| F-45 | 连续两个位移控制 | A=500、B=600，A 本 tick 同时被「击退 +2 格」与「拉近 1 格」 | 按 `05-effects` §4.2 优先级：**位移取首个**（按效果加入顺序），本例取「击退 +2 格」→ A 钳到 **536** + 碰撞伤害 |
