## 1. 统一示例基准（所有示例共用，保证数字可交叉复算）

| 项 | 值 |
|---|---|
| 场地 | 16 格 × **64px** = **1024px**；格心 `64c+32`；角色中心 clamp `[32, 992]` |
| 角色 A（近战） | atk **12** / def **8** / hp **132** / sp **72** / mp **41** / 暴击 **8.16%** / 吸血 **10.2%** |
| 角色 B（远程） | atk **19** / def **9** / hp **110** / sp **63** / mp **34** / 吸血 **10.2%** |
| 速度 | `move` = 64px；`dodge` = 128px；位移技能 = `distance × 64px`；弹幕 = `range × 64px` |
| 减伤系数 | A 受击 `1−8/48 = 0.833333`；B 受击 `1−9/49 = 0.816327`；基地 `1−64/104 = 0.384615` |
| **碰撞伤害** | A→B = `12×0.8×0.816327 = 7.837` → **7**；B→A = `19×0.8×0.833333 = 12.667` → **12** |
| 示例位移技能「突进斩」 | `distance 4`（256px）、`multiplier 1.3` → A 打 B = `12.735` → **12**；B 打 A = `20.583` → **20** |
| 伤害取整 | 所有倍率相乘后**只取整一次**（D-41），下限 1 |
| 示例平射 | `range 8` → `v = 512px/tick`；示例 AOE | `range [0,2]`、L2、`mult 1.3` |

## 3. 示例的统一书写格式

```
【编号】X-x　【分支】…
① 前置状态：位置/朝向/资源/CD/效果
② 双方意图（AI 或硬编码）
③ 判定过程：连续方程、比较、优先级（逐步）
④ 结果：位置 / 伤害 / 资源 / 事件（含 cid 与 1px 位置）
⑤ 依据：D 编号 / systems 章节
⑥ 若涉及未定义子项：标注 ⚠ U-x / V-x 并给出建议默认
```

**机器复算要求**：每篇示例写完后必须配一个 `.audit/verify-*.js`，按其描述重新计算全部数值并核对；通过后**删除脚本、保留数值**。已执行：

| 校验器 | 覆盖 | 结果 |
|---|---|---|
| `.audit/verify-movement.js` | 移动与碰撞 18 例 | ✅ 通过（修正 3 处接触点、1 处碰撞判据） |
| `.audit/verify-bullets.js` | 平射/AOE/碰撞/衰减 | ✅ 通过（修正 1 处双消位置描述） |
| `.audit/verify-rest.js` | 物品/角色/技能/效果/解锁/排位 | ✅ 通过（数值与文档一致） |
