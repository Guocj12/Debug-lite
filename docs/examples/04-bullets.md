# 示例集 · 弹幕系统（全分支）

> 依据：`decisions.md` **D-20 ~ D-32**；实现细则见 `systems/04-bullets.md`。
> 基准数值见 `examples/README.md` §1。本文件所有 `t*`、位置、伤害均由 `.audit/verify-bullets.js` 按连续方程复算得出。
> 关键前提：**弹幕不跨 tick**（每枚在生成当 tick 飞完射程并结算完），**没有"经过的格"列表**。

---

## 1. 平射命中：连续方程 `x_b0 + vb·t = x_c0 + vc·t`

**A 的开火技能**（示例）：`range 8` → `v = 8×64 = 512px/tick`，`mult 1.0`，L3；**命中区间 `t ∈ (0, 1]`（含终点，D-30）**。
对 B 的基础伤害（B def 9）：`12×1.0×0.816327 = 9.796` → **9**。

| # | 分支 | 参数（B 的轨迹） | 解算 | 结果 |
|---|---|---|---|---|
| **P1** | **相向**（弹幕向右、B 向左） | B 800 → 736（−64） | `t* = (800−224)/(512−(−64)) = 576/576 = **1.0**` | **命中 @736**（t=1 含终点），伤害 **9** |
| **P2** | **同向追及**（弹幕更快，追上） | B 400 → 464（+64） | `t* = (400−224)/(512−64) = 176/448 = 0.3929` | **命中 @425** |
| **P3** | 同向、**弹幕更慢**（追不上） | B 400 → 464；弹幕 `v=128` | `t* = 176/(128−64) = 2.75 > 1` | **不命中** |
| **P4** | **等速平行** | B 400 → 464；弹幕 `v=64` | `512−64` 换成 `64−64 = 0` → 无解 | **不命中** |
| **P5** | **目标静止** | B 停在 400 | `t* = 176/512 = 0.3438` | **命中 @400** |
| **P6** | **背离**（目标在弹幕后方） | B 在 300（弹幕从 400 向右） | `t* = (300−400)/512 = −0.195 < 0` | **不命中**（弹幕离它而去） |
| **P7** | 同向但**够不着** | B 800 → 864（+64） | `t* = 576/448 = 1.2857 > 1` | **不命中**（本 tick 内追不上） |

> **要点**：命中判定不是"路径上有没有敌人"，而是**解出同一时刻位置相等**。P1 与 P3 参数相近但结果相反（相向必中 vs 同向追不上），P7 则是"弹幕更快却仍不中"。

## 2. AOE（速度 0）分支

**A 的重击**：`range [0,2]`、L2、`mult 1.3`；A 在 736（格 11）→ 覆盖格 **11/12/13** → 三枚 0 速弹幕 @ **736 / 800 / 864**。
判定用**目标本 tick 位移后的位置**（D-24）。

| # | 情形 | B 的落位 | B 所在格 | 判定 | 伤害 |
|---|---|---|---|---|---|
| **Q1** | B 静止 | 800 | 12（在范围内） | **命中** | `12×1.3×0.816327 = 12.735` → **12** |
| **Q2** | B 移动 64 | 800 → 864 | 13（**仍在范围内**） | **命中** | **12** |
| **Q3** | B 闪避 128 | 800 → 928 | 14（**出范围**） | **躲开** | — |
| **Q4** | B 反向**退一格**（朝 A 方向） | 800 → 736 | 11（**仍在范围内**） | **命中** | **12** |

> **要点**：Q2 说明"退一格躲不开 AOE"（范围 [0,2] 覆盖 3 格）；Q3 才真正躲开。

### 2.1 每格独立 + `falloff` 衰减

设 A 的重击 `falloff = 0.2`（每向外一格 −20%），**中心格 = 施法者所在格 736**：

| B 的落点 | 与中心格的距离 | 倍率系数 | 伤害 |
|---|---|---|---|
| 736（格 11，中心） | 0 格 | ×1.0 | `12.735` → **12** |
| 800（格 12） | +1 格 | ×0.8 | `10.188` → **10** |
| 864（格 13） | +2 格 | ×0.6 | `7.641` → **7** |

- **每格一枚独立弹幕**（D-26）：因此 B 站在 800 时，**只有 800 那枚**会命中它（其它两枚各自判定、各自参与抵消）。
- `falloff = 0`（默认）时三格伤害相同（12/12/12）。

## 3. 弹幕互撞（连续方程 + 等级矩阵）

**碰撞判据**：解 `x₁0 + v₁t = x₂0 + v₂t`，`t ∈ [0, 1]`（**含 t=0**，D-32）。

### 3.1 碰撞位置复算

| # | 双方弹幕 | 解算 | 碰撞位置 |
|---|---|---|---|
| **C1** | A 平射 @224 `v=+512` vs B 平射 @800 `v=−320` | `t* = (800−224)/(512−(−320)) = 0.6923` | **578** |
| **C2** | A 的 AOE @800 `v=0` vs B 平射 @800 `v=−512` | `t* = 0` → **立即拦截**（D-32） | **800**（生成点） |
| **C3** | A 的 AOE @736 `v=0` vs B 平射 @800 `v=−320` | `t* = (800−736)/320 = 0.2` | **736** |
| **C4** | A 平射 @224 `v=+512` vs B 平射 @800 `v=−512` | `t* = 576/1024 = 0.5625` | **512** |
| **C5** | 同向平行（同速度、间距固定） | `v₁−v₂ = 0` → 无解 | **不相遇** |

### 3.2 等级矩阵（数字小 = 等级高）

| 高→低 | L1 | L2 | L3 | L4 |
|---|---|---|---|---|
| **L1** | 双消 | L1 穿过 | L1 穿过 | L1 穿过 |
| **L2** | L1 穿过 | 双消 | L2 穿过 | L2 穿过 |
| **L3** | L1 穿过 | L2 穿过 | 双消 | L3 穿过 |
| **L4** | L1 穿过 | L2 穿过 | L3 穿过 | 双消 |

**"穿过"的完整含义**：胜者**继续飞完全射程并照常判定命中**（D-28），不是简单地"无事发生"。

### 3.3 三个必看组合

| # | 组合 | 结果 |
|---|---|---|
| **C6 高穿低且继续命中** | A 的重击（**L2**）覆盖 B 所在格；B 同时放出 **L4** 冰锥 | 在交点处 L4 被消，**A 的 L2 继续判定并命中 B**（伤害 12） |
| **C7 低被高消（攻击方吃亏）** | A 放出 **L4** 平射打向 B；B 用 **L2** 近战起手 | A 的 L4 在飞行途中被 B 的 L2 抵消 → **A 这一发完全失效**（B 不受该发伤害） |
| **C8 同级双消 = 等价交换** | A 的重击覆盖 B 所在格（800）；B **就在 800 开火**放 **L2** 平射 | 二者在 **t=0 于 800 处双消**（D-32）：A 的 @800 AOE 与 B 的子弹**同时消失** → **双方都无伤**（A 失去那次命中、B 失去那发输出） |
| **C9 递归处理** | A 有 AOE @736(L2) 与 @800(L2)；B 从 800 放出 **两枚** L3 平射 | 按生成顺序：两枚均在 **t=0 于 800** 与 A 的 @800 相遇（D-32 立即拦截，先于与 @736 的 t>0 相遇）→ 各被 L2 高穿低消掉 → **A 的两枚 AOE 都存活，B 的两发全废**，随后 A 的 @800 命中 B（12）<br>⚠ 若把第 2 枚换成 **L2**，则第 2 枚与 A 的 @800 **同级双消**，@800 消失后 A 的 @736 覆盖不到 B（B 在格 12）→ **A 反而失去命中** —— 这就是"移除会改变后续判定"的递归语义 |

> **C8/C9 是同一机制的两面**：抵消不是"预先算好的静态列表"，而是**逐条按当前存活集合**处理的结果；因此实现必须用"可移除的候选集合 + 顺序遍历"（D-27），不能用一次性快照。
