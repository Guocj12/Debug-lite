# 示例集 · 移动与角色碰撞（全分支）

> 依据：`decisions.md` **D-06 ~ D-18、D-32**；实现细则见 `systems/07-engine.md` §4.3、`systems/06-field.md`。
> 基准数值见 `examples/README.md` §1（A：atk12/def8；B：atk19/def9；碰撞伤害 A→B=**7**、B→A=**12**；位移技「突进斩」256px / 倍率 1.3 → A→B=**12**、B→A=**20**）。

## 1. 统一落位算法（把 D-10 ~ D-18 收敛为可执行 5 步）

```
输入：双方动作意图（move / dodge / 位移技能 / 静止）及其"可穿标志"
1. 各自算出「意图目标位置」T1, T2（clampX 后）；可穿标志：
     move          → 不可穿
     dodge         → 可穿（默认）
     位移技能       → 看模板 passThroughEnemy
     控制类位移     → 不可穿
2. 若「双方都不可穿」且两者轨迹在 t∈[0,1] 内会使中心距 < 64px（含交错/重叠）：
     → 碰撞：解 gap(t) = 64 得 t*，双方停在 t* 时刻位置
     → 双方各受对方 atk×0.8 的碰撞伤害
3. 否则（至少一方可穿，或不会相遇）：
     → 各自到达 T1 / T2
     → 若到达后中心距 < 64px（仅"目标重叠"可能），按可穿情况后推：
           · **双方都可穿** → 各自**再沿原方向前进一格**（+64px），**相遇格空着**（D-33，中心距 128px）
           · **仅一方可穿**（另一方静止/被让位）→ 可穿方停在**敌方身后**（敌方位置 ± 64px，中心距恰好 64px）
4. 位移技能额外按 D-18 结算伤害（见 §4）
5. 撞基地（D-61）：意图目标越过 [32,992] 且朝向基地 → 停在原地 + 对基地 atk×0.8
```

> **判定条件注意**：第 2 步的碰撞条件是"中心距**会小于** 64px"；**恰好到达 64px 不算碰撞**（那是"移动到相邻"）。

## 3. 详细推演（选 3 例，含连续方程与 1px 输出）

### 3.1 M5 —— 位移技撞上静止方（**弹幕 + 碰撞双结算**，D-18 统一模型）

```
① 前置：A = 400px（朝右 f=+1），B = 600px（朝左 f=−1）；gap = 200
② 意图：A 释放「突进斩」（passThroughEnemy=false、dealDamage=true、distance=4 → 256px）
        → 意图目标 656px（会越过 B）；B 执行 defend（不移动）
③ 判定：
   · A 不可穿 + B 静止 + 目标位置会使 gap<64 → 碰撞分支
   · 解 gap(t)=64：gap(t) = (600) − (400 + 256t) = 200 − 256t = 64  →  t* = 136/256 = 0.53125
   · 碰撞时刻：A = 400 + 256×0.53125 = 536；B = 600（未移动）
   · **接触点** = 双方中点 = (536+600)/2 = **568**（1px 精度输出给前端）
④ 结果：
   · 位置：A = 536、B = 600（gap = 64 ✓）
   · 伤害（**两次独立结算**，D-18 统一模型）：
         **① 路径弹幕**：A 的声明路径 400→656 覆盖格 6~10（px 416/480/544/608/**672**）→ B 在 600（格 9）**在路径内** → 该格 0 速弹幕命中 → **技能伤害** 12×1.3×0.816327 = 12.735 → **12**（等级取模板 `bulletLevel`，参与抵消）
         **② 碰撞伤害**：碰撞成立 → 双方各受对方 `atk×0.8`：B 受 **7**、A 受 **12**
   · **B 本 tick 合计承受 19（12 + 7）**；A 承受 **12**
   · 事件：`bullet.spawn`(debug，路径 5 枚) → `bullet.hit`(debug, @600) → `damage.calc` ×3（1 次弹幕 + 2 次碰撞）→ `collision.resolve`(info, atX=**568**)
   · cid：路径弹幕命中记 `t{此tick}:p1:1`；碰撞伤害记 `t{此tick}:collision`
⑤ 对照 M6：若 dealDamage=false → **不放置路径弹幕**，只剩碰撞伤害（B 受 7、A 受 12）
⑥ 对照 M4：若 A 可穿（passThroughEnemy=true）→ 穿过 B、无碰撞 → 只有路径弹幕的 **12**
```

### 3.2 N3 —— 相向移动至**同格**（双方都不可穿）

```
① 前置：A = 400（f=+1）、B = 528（f=−1）；gap = 128
② 意图：A move_right → 464；B move_left → 464   ← 两者目标位置完全相同
③ 判定：
   · 双方都不可穿（move）且 gap 将变为 0 → 碰撞分支
   · gap(t) = (528 − 64t) − (400 + 64t) = 128 − 128t = 64  →  t* = 0.5
   · 碰撞位置中点 = A 432 与 B 496 之间 → **464**（两人的"相遇点"）
④ 结果：A = 432、B = 496（gap = 64 ✓，各自停在相遇点左/右）
   · 伤害：A 受 12、B 受 7（双向碰撞伤害，D-10）
   · 两者都**没有**到达自己原本的意图位置（464）——这正是"目标重叠 → 碰撞"的语义
⑤ 对照：若 A 改用 dodge（可穿），则进入 N4/N5 分支，A 会真的穿过 B
```

### 3.3 N5 —— 相向**互穿**（双方都可穿）

```
① 前置：A = 400（f=+1）、B = 528（f=−1）；gap = 128
② 意图：A dodge_right（128px）→ 528；B dodge_left（128px）→ 400
③ 判定：
   · 至少一方可穿（双方都可穿）→ 跳过碰撞分支
   · 各自到达目标：A→528、B→400；到达后 gap = |528−400| = 128 ≥ 64 ✓
④ 结果：**双方互换位置**：A = 528、B = 400
   · 无碰撞、无碰撞伤害（D-11：可穿方穿过敌人到达目标位置）
   · 事件只记 `move.resolve`(debug)，带 1px 的 fromX/toX
⑤ 对照 N6：若两者目标位置**相同**（同为 528），则触发 ⚠U-2 的对称展开
```

## 4. 位移技能的伤害模型（D-18，2026-09-11 统一版）

> **核心**：位移技不再有独立的伤害代码路径——`dealDamage=true` 就是**沿声明的移动路径每格放一枚 0 速弹幕**，与近战/垂直 AOE **完全同构**。
> 因此：**弹幕伤害与碰撞伤害分别结算，同一 tick 可能受两次伤害**。

**路径定义**：`caster.x → clampX(caster.x + 朝向 × distance × cellPx)`，**与是否被碰撞截停无关**（否则不可能出现"弹幕+碰撞"双结算）。

| 可穿 | 有伤 | 穿过敌人 | 碰撞（不可穿且撞上） |
|---|---|---|---|
| ✅ | ✅ | 路径弹幕命中 → **技能伤害**；无碰撞 → 只受一次 | —（可穿不会碰撞） |
| ✅ | ❌ | **无伤害** | — |
| ❌ | ✅ | — | **两次伤害**：路径弹幕命中（**技能伤害**）**+** 碰撞伤害（双方各 `atk×0.8`） |
| ❌ | ❌ | — | **一次伤害**：碰撞伤害（双方各 `atk×0.8`），无路径弹幕 |

**示例（A 用突进斩：路径 400→656，覆盖格 6~10）**

| # | 场景 | 路径弹幕 | 碰撞伤害 | B 合计承受 | A 承受 |
|---|---|---|---|---|---|
| **M4** | 可穿+有伤，B 在 500（格 7，**在路径内**） | 命中 → 12 | — | **12** | 0 |
| **M5** | 不可穿+有伤，B 在 600（格 9，**在路径内**）→ 碰撞，A 停在 536 | 命中 → 12 | B 7 / A 12 | **19**（12+7） | **12** |
| **M6** | 不可穿+**无伤**，同 M5 | 无 | B 7 / A 12 | **7** | **12** |
| **M7** | 可穿+**无伤**，B 在 500 | 无 | — | **0** | 0 |
| **M8** | 有伤，B 在 720（格 11，**不在路径内**） | 无 | 无（恰好相邻） | **0** | 0 |

> **M8 无需特判**：因为"恰好相邻"时敌人不在声明路径内，自然不会被打到——这正是原 D-19 想表达的规则，现在由模型自动保证。
> **M4 vs M5** 的差别就是"路径内命中"与"路径内命中 + 碰撞"两次结算。

### 4.1 与其他系统的统一性

| 项 | 位移路径弹幕 | 近战 AOE | 垂直 AOE | 平射 |
|---|---|---|---|---|
| 速度 | **0** | 0 | 0 | `range×64` |
| 生成位置 | 路径每格 | 覆盖格每格 | `area` 覆盖格每格 | 释放者所在格 |
| 命中基准 | 目标**位移后**位置 | 同左 | 同左 | **连续方程求交** |
| 参与抵消 | ✅ | ✅ | ✅ | ✅ |
| 每目标次数 | 最多 1（每格一枚，但同一格只判一次） | 最多 1 | 最多 1 | 可多次 |
