# 部署指南

## 一、服务器环境要求

- **OS**: Ubuntu 20.04+ / CentOS 7+ / Windows Server
- **Node.js**: 18.x LTS 或更高
- **Nginx**: 任意版本（可选，推荐）
- **内存**: Node 进程约 50-150MB，2核2G 完全够用

---

## 二、安装 Node.js

```bash
# Ubuntu/Debian
curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
sudo apt-get install -y nodejs

# 验证
node -v   # 应输出 v18.x.x
npm -v    # 应输出 9.x.x
```

---

## 三、安装 pm2（进程守护）

```bash
npm install -g pm2

# 设置开机自启
pm2 startup
# 按提示执行输出的命令
```

---

## 四、安装项目依赖 & 启动

```bash
cd /path/to/Game/Debug-lite/server

# 安装依赖
npm install

# pm2 启动
pm2 start index.js --name neon-battle

# 查看状态
pm2 status

# 查看日志
pm2 logs neon-battle

# 保存 pm2 进程列表（重启后恢复）
pm2 save
```

## 五、Nginx 反向代理配置

假设你的服务器 IP 是 `1.2.3.4`，域名是 `game.example.com`。

```nginx
# /etc/nginx/sites-available/neon-battle
server {
    listen 80;
    server_name game.example.com;  # 或直接用 IP

    # 静态文件
    location / {
        root /path/to/Game/Debug-lite/public;
        index index.html;
        try_files $uri $uri/ /index.html;
    }

    # WebSocket 代理到 Node
    location /socket.io/ {
        proxy_pass http://127.0.0.1:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_read_timeout 86400s;  # WebSocket 长连接
    }
}
```

```bash
# 启用配置
sudo ln -s /etc/nginx/sites-available/neon-battle /etc/nginx/sites-enabled/
sudo nginx -t          # 检查配置
sudo systemctl reload nginx
```

### 如果不用域名，只通过 IP 访问

server_name 设为 `_`，访问 `http://1.2.3.4` 即可。

## 六、HTTPS 配置（推荐）

sudo certbot --nginx -d game.example.com

## 七、防火墙

```bash
# 开放 80/443 端口
sudo ufw allow 80
sudo ufw allow 443
sudo ufw enable

# 注意：3000 端口不对外开放，只通过 Nginx 内部转发
# 如果不用 Nginx 直接用 Node，则需开放 3000
sudo ufw allow 3000
```

## 八、客户端连接配置

前端 `socket.js` 中：

```javascript
// 开发环境（本地测试）
const SERVER_URL = 'http://localhost:3000';

// 生产环境（通过 Nginx 反代，无需端口）
const SERVER_URL = 'https://game.example.com';  // 或 http://1.2.3.4
// 注意：通过 Nginx 反代时端口写 80/443，不用写 3000

const socket = io(SERVER_URL, {
    transports: ['websocket', 'polling'],
    reconnection: true,
    reconnectionDelay: 1000,
    reconnectionAttempts: 10
});
```

## 九、与 AstrBot 共存

AstrBot 通常运行在另一个端口（如 8080 或 5000）。Node 游戏服务器用 3000，互不冲突。

如果都用 Nginx 反代：

```nginx
server {
    listen 80;
    server_name _;

    # 游戏
    location / {
        root /path/to/Game/Debug-lite/public;
    }
    location /socket.io/ {
        proxy_pass http://127.0.0.1:3000;
        # ... websocket headers
    }

    # AstrBot（如果也通过 Nginx）
    location /bot/ {
        proxy_pass http://127.0.0.1:8080;
    }
}
```

## 十一、快速启动清单

```bash
# 1. 上传代码到服务器
scp -r f:/Game/Debug-lite user@1.2.3.4:/home/user/

# 2. SSH 登录
ssh user@1.2.3.4

# 3. 安装 Node.js（仅首次）
curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
sudo apt-get install -y nodejs

# 4. 安装 pm2（仅首次）
npm install -g pm2

# 5. 安装依赖
cd /home/user/Debug-lite/server
npm install

# 6. 启动
pm2 start index.js --name neon-battle
pm2 save

# 7. 配置 Nginx（仅首次）
sudo nano /etc/nginx/sites-available/neon-battle
# 粘贴上面的 Nginx 配置
sudo ln -s /etc/nginx/sites-available/neon-battle /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx

# 8. 测试
# 浏览器打开 http://1.2.3.4
```
