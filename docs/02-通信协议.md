# 通信协议设计

## 连接

客户端连接服务端：`const socket = io('http://服务器IP:3000');`

服务端端口：`3000`

---

## 一、客户端 → 服务端（emit）

### 1.1 创建房间
```javascript
socket.emit('create_room', {
    playerName: '玩家小明'
});
```

### 1.2 加入房间
```javascript
socket.emit('join_room', {
    roomId: 'A3F2',
    playerName: '玩家小红'
});
```

### 1.3 选择技能（准备阶段前）
```javascript
socket.emit('select_skills', {
    roomId: 'A3F2',
    skillIds: ['fireball', 'shield_bash', 'quick_step']
});
```

### 1.4 更新行动队列（准备阶段，每次修改都发送）
```javascript
socket.emit('update_queue', {
    roomId: 'A3F2',
    queue: [
        { action: 'move', direction: 'right' },
        { action: 'defend' },
        { action: 'skill', skillId: 'fireball' },
        { action: 'attack' },
        { action: 'move', direction: 'left' }
    ]
});
```
队列中每个 action 的类型：
- `move`：移动（需 direction: 'left'|'right'|'up'|'down'）
- `attack`：普通攻击
- `defend`：防御
- `skill`：释放技能（需 skillId）

### 1.5 锁定队列（准备时间结束或手动确认）
```javascript
socket.emit('confirm_queue', {
    roomId: 'A3F2'
});
```

### 1.6 离开房间
```javascript
socket.emit('leave_room', {
    roomId: 'A3F2'
});
```

### 1.7 请求重新开始
```javascript
socket.emit('request_rematch', {
    roomId: 'A3F2'
});
```

## 二、服务端 → 客户端（on 监听）

### 2.1 房间创建成功
```javascript
socket.on('room_created', (data) => {
    // data: { roomId: 'A3F2', playerId: 'p1' }
});
```

### 2.2 对手加入
```javascript
socket.on('opponent_joined', (data) => {
    // data: { opponentName: '玩家小红', opponentCharacter: null }
});
```

### 2.3 对手选择了角色/技能
```javascript
socket.on('opponent_skills_selected', (data) => {
    // data: { skillCount: 3 }  // 不暴露具体技能，只告知已选
});
```

### 2.4 游戏开始
```javascript
socket.on('game_start', (data) => {
    // data: { 
    //   you: { id, name, hp, maxHp, characterId, skills: [...], position },
    //   opponent: { id, name, hp, maxHp, characterId, skills: [...], position },
    //   round: 1
    // }
});
```

### 2.5 阶段切换
```javascript
socket.on('phase_change', (data) => {
    // data: { phase: 'prepare', timeLeft: 60 }
    // data: { phase: 'battle', round: 1 }
    // data: { phase: 'game_over', winner: 'p1' }
});
```

### 2.6 每秒计时
```javascript
socket.on('tick', (data) => {
    // data: { timeLeft: 45 }
});
```

### 2.7 对手队列长度变化（不暴露具体内容！）
```javascript
socket.on('opponent_queue_update', (data) => {
    // data: { length: 5, confirmed: false }
});
```

### 2.8 战斗行动播报（逐条播放）
```javascript
socket.on('battle_action', (data) => {
    // data: {
    //   stepIndex: 0,          // 第几步
    //   actions: [
    //     { playerId: 'p1', action: 'move', direction: 'right', newPosition: {x:3,y:0} },
    //     { playerId: 'p2', action: 'defend', effect: 'shield_up' }
    //   ],
    //   results: [
    //     { playerId: 'p1', hpChange: 0, newHp: 100 },
    //     { playerId: 'p2', hpChange: -8, newHp: 72 }
    //   ]
    // }
});
```

### 2.9 回合结束
```javascript
socket.on('round_end', (data) => {
    // data: {
    //   round: 1,
    //   players: [
    //     { playerId: 'p1', hp: 100, buffs: [...], skillCooldowns: {...} },
    //     { playerId: 'p2', hp: 68, buffs: [...], skillCooldowns: {...} }
    //   ]
    // }
});
```

### 2.10 游戏结束
```javascript
socket.on('game_over', (data) => {
    // data: {
    //   winner: { id: 'p1', name: '玩家小明' },
    //   loser: { id: 'p2', name: '玩家小红' },
    //   totalRounds: 5,
    //   stats: { p1: { damageDealt: 150, ... }, p2: {...} }
    // }
});
```

### 2.11 对手断开
```javascript
socket.on('opponent_disconnected', (data) => {
    // data: { message: '对手已断开连接，等待重连...', timeout: 30 }
});
```

### 2.12 对手重连
```javascript
socket.on('opponent_reconnected', (data) => {
    // data: { opponentName: '玩家小红' }
});
```

### 2.13 错误消息
```javascript
socket.on('error_msg', (data) => {
    // data: { message: '房间不存在' }
});
```

## 三、完整游戏流程（通信视角）

```
客户端A                   服务端                   客户端B
  │                        │                        │
  │── create_room ────────→│                        │
  │←─ room_created ───────│                        │
  │                        │                        │
  │                        │←── join_room ──────────│
  │← opponent_joined ──────│── opponent_joined ────→│
  │                        │                        │
  │── select_skills ──────→│←── select_skills ──────│
  │← opponent_skills_sel ──│── opponent_skills_sel →│
  │                        │                        │
  │                        │── game_start ────────→│
  │←── game_start ────────│── game_start ──────────│
  │                        │                        │
  │                        │  [准备阶段 60s]         │
  │←── phase_change ──────│── phase_change ───────→│
  │←── tick (每秒) ────────│── tick (每秒) ────────→│
  │── update_queue ───────→│←── update_queue ──────│
  │← opponent_queue_update │── opponent_queue_upd →│
  │                        │                        │
  │── confirm_queue ──────→│←── confirm_queue ─────│
  │                        │                        │
  │                        │  [战斗阶段]             │
  │←── phase_change ──────│── phase_change ───────→│
  │←── battle_action*N ───│── battle_action*N ────→│
  │                        │  (逐个步骤播报)         │
  │←── round_end ─────────│── round_end ──────────→│
  │                        │                        │
  │             [若无人死亡，回到准备阶段]             │
  │                        │                        │
  │←── game_over ─────────│── game_over ──────────→│
```

## 四、注意事项

1. **对手队列内容绝对不传**：对方只能看到你的队列长度和是否已确认
2. **服务端是唯一真理**：所有伤害计算、位置判定、胜负判定都在服务端
3. **断开处理**：任一方断开，给对方 30 秒等待时间，超时判负
4. **房间清理**：游戏结束后 5 分钟自动清理房间
