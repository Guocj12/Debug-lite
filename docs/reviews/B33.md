## 交付物摘要

- **Bearer 鉴权中间件**：`Authorization: Bearer <token>`；`store_unavailable`(503) / `session_expired`(401) / `forbidden`(403) 分列。实测可达状态码：401/403/404/409/410/413/429/503。
- **`DL_LEGACY_STATELESS` 默认 `1`**：旧无状态端点（`box`/`warehouse*`/`loadout`/`panel`/`ai/*`/`battle`）零回归；置 `0` → 遗留端点 **410 `deprecated`**（`ranked/run|promote` 变鉴权端点而非 410）。
- **回放治理**：进程内 **LRU 64**（`store.config.replayCacheSize`）+ **参与者鉴权 403 `replay_forbidden`** + 淘汰/版本不匹配/快照失效 → **410 `replay_expired`**；`b_` 型归档回放**按需重算**（不受 `DL_LEGACY_STATELESS` 影响）。
- **`readBody` 超限 → 413 `payload_too_large`**（原为 500 `internal_error`）。
- **CLI**：新增 `auth register|login|logout|change-password`、`me`、`quick run`、`leaderboard`、`ranked promote`；**退出码 `3` = 未鉴权**（`0/1/2` 语义不变）；token 来源优先级 `--token` > `options.token` > `DL_TOKEN`。
- **路径别名**：`/auth/change-password` ≡ `/auth/password`、`/me/records/seen` ≡ `/me/seen`（两条都注册，`index.js:894-895`）。
- **admin**：`POST /api/v1/admin/{bots,rebuild-index,stats,clear-bots,ban,unban}`；**令牌 + `DL_DEBUG_BOTS` 双门控**（bot 注入默认关闭 → 403 `debug_bots_disabled`；`DL_ADMIN_TOKEN` 未配置 → 503 `admin_token_missing`）；封禁/解封写 journal（`account.banned`/`account.unbanned`）。
- 新错误码：`payload_too_large`(413)、`deprecated`(410)、`rate_limited`(429，属限流中间件)、`store_unavailable`(503)、`replay_forbidden`(403)、`replay_expired`(410)、`pool_forbidden`(400)、`admin_token_missing`(503)。
