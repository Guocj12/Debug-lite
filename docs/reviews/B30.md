## 交付物摘要

- `/me/records` 返回字段：`records / since / latestSeq / limit / role / unread / maxSeq`。
  - **`nextSince` 已改名 `latestSeq`**：语义 = **本次返回里最大的 seq**（展示/去重用途）；**游标推进只由 `records/seen` 负责**，`limit` 截断时把 `latestSeq` 当 `since` 回传会跳过更早的未读战绩（`account.js:523-525` 注释即契约）。
  - `role` 过滤（`attacker`/`defender`）与 `since` 增量读取已实现。
- `/me/records/seen`：`uptoSeq` 必填非负整数，纯 A 类写（**不动 `appliedSeq` 水位**）；同义别名 `/me/seen` 两条路径都注册（`index.js:895`）。
- `/me/defense`：被抽场次（`drawnCount`）/ 胜负 / 最近列表 / 未读。
- `/leaderboard?scope=global|tier:<t>&limit=`：内存索引排序（points 降序 → peakPoints → updatedAt），`bad_scope` → 400；响应只给 `publicId + nickname`，**不回带 `playerId`**。
