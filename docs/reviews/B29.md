## 交付物摘要

- 注册事务内冻结默认快照（`defaultLoadout()` = `role_bal` + 3 个 common 技能 + 兜底 AI）→ `slot1`（`isDefault`）→ 唯一出战。

- 快照冻结：深拷贝 + canonical hash + `engineVersion/dataVersion/configHash` 版本戳；**磁盘文件名去掉 `sha256:` 前缀**（`canonical.js:46-48`；Windows 文件名不允许 `:`），分片 = 去掉前缀后 hex 的**前 2 个字符**。
