关键断言：
- **用户硬要求「后端加能力 → 面板必须同步」= 机器强制**：`admin-op-parity` 从**后端源码**解析 admin 能力集合，与前端 `public/api.js` 的 `ADMIN_OPS` **双向断言相等**（后端新增 op 而面板未登记 → FAIL）。
- **分页无上限**：AF 造 **106 个账号**，每页 50/100 逐页取完 → `total` 正确、**无重复无遗漏**、**未被 100 截断**；`limit>200`/`offset<0` → 400；越界 offset → 空 rows + `hasMore=false`。
- **删除**：二次确认（取消 → 仍在；确认 → 列表缩 1 → 被删账号登录 401 → 重复删 404）；**删自己 → 409 `cannot_delete_self`**。
- **三条授权路径**：管理员账号 Bearer（无需令牌）200 / 普通账号 403 / 令牌路径 200（错误令牌 403、未配置 503）——其中令牌路径在 UI 侧不可达（§13-8），由 AF-3 在 api 层覆盖。
- **模块不变量**（去注释后静态扫描 `public/*.js`）：`fetch(` 只在 `api.js`、`innerHTML` 只在 `app.js`、`pick(` 只在 `format.js`、非 `format/contract` 文件无任何响应字段字面量 → OK。
- **令牌不落盘**：AF 断言 `localStorage` 仅含 `dl.token`/`dl.session`，**不含**管理员令牌。
