## 交付物摘要

- **`BOT_LD` 已删除**（实测 `require('./server/ranked.js').BOT_LD === undefined`）；池只来自真实档案：`byTier ∩ 可用快照 ∩ 未封禁 ∩ 在池 ∩ 排除自己`。
- 池不足 → **如实回报 `shortfall`**（字段名就是 `shortfall`，不是 `no_opponent`）；**禁止占位 bot 充数**（D-152）。
- **去重窗口裁定（用户 2026-09-16）**：`strict` = 间隔 ≥ 72h（优先）；`relaxed` = 24h ≤ 间隔 < 72h（strict 凑不满时启用并记 `relaxed:true`）；**间隔 < 24h 两池皆拒 —— 24h 是硬底线，永不"允许重复"**；仍不足 → `shortfall`。
- **双向记账**（D-132/D-134）：发起者 `stats.attack` 同步结算；防守方离线只记 `stats.defense`/`recent`，**不掉段不掉分**；`battleId` 幂等（`b = f(batchId|matchIndex|seed|p1SnapshotHash|p2SnapshotHash)`）。
- `batchId` 由 `(playerId, seed)` **确定性派生**（`ranked.js:295-300`）：同 seed 重发命中既有批次，不重复结算、不重复触发晋升。
- **晋升在 `/ranked/run` 内落地**（`shortfall === 0` 才判段位）；`/ranked/promote` 只做**判定**（读档案段位，入参 `tier` 不一致 → 403 `forbidden`），**不落盘**。
- `pool` 入参 → **400 `pool_forbidden`**（服务端抽池，D-136 不接受客户端自选对手）。
- `DL_LEGACY_STATELESS=1`（默认）且无 token → 遗留无状态路径（`loadout/warehouse/pool/tier` 由请求传入）；`=0` 时无 token → 401。
