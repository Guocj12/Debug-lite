## 缺口自查（四项按任务要求逐条）

① **解码型穿越（%2e%2e）**：**任务假设不成立——当前无泄漏面（实证）**。`/js/%2e%2e/server/index.js` 实际结果 **404 unknown_endpoint，响应体为 JSON 信封，绝不含 server/index.js 源码**（probe1 全矩阵 10 个编码变体逐一断言无泄漏）。机制：Node `http` 不解码 `req.url`（urlPath 原文）；`path.join` 亦不解码——`%2e%2e` 只是**字面目录名**，readFileSync → ENOENT → null → 404。**严重性判定：非 P0/P1**——静态面只读、无写入面、无当前泄漏路径；但防御依赖「任何一层都不得对 urlPath 先解码」的**隐含不变量**（未来若为日志/规范化加入 decode 即漏网），且 `abs.startsWith` 根检查是本该兜底它、却不可达的死代码 → **P2-1（建议随批落实）**：staticFile 入口 `decodeURIComponent(urlPath)`（失败 → 400）后再判 `..`/`\`，一行消除不变量，`%2e%2e` 变体从「404 漏网兜底」升级为「400 显式拒绝」，api-static 的 400/404 双可断言随之收紧为单 400。

② **assets/ 前缀存在性**：**可接受**。`assets/` 目录存在（animations.json/sprites.json/README.md，P0-9 占位美术表），`/assets/sprites.json` 实测 **200**（application/json）、`/assets/nope.json` 实测 **404**——前缀本身无空转。唯一缺口：**无套件覆盖**（api-static 只测到 /shared/；server/index.js 不在阈值目录、门禁不查）→ P2-8（补两行断言）。

③ **gate 项 7 对 public/js 的新增文件纪律**：**正向约束实证成立**。onDisk 扫描含 public/js：当前 app.js/util/log.js 均被 util-log.test.js import（cov 报表在列）；未来任何新增 public/js 文件若不被任何测试 import → 「未被任何测试加载（覆盖率 0%）」→ 项 7 FAIL——纪律自动生效，登记（P2-4 内部含）。

④ **index.html 的 UMD/shared 与 public ESM 混用**：**F0 设计意图，非缺陷（登记）**。`<script src="/shared/log.js">`（经典脚本装 window.DLLog）→ util/log.js 浏览器分支经 window.DLLog.createLogger **另建独立实例**——前端自持 logger，双实例并存；UMD 文件无 ESM export，未来 public 模块若直接 `import 'shared/log.js'` 会得空命名空间；check-arch 只扫 .js 不扫 HTML（index.html script 标签无规则面）→ P2-5（F1 建议 ESM 包装统一单例或显式登记双实例纪律）。

### P2 登记（不阻塞；P2-1 建议随批落实）

1. **P2-1（编码穿越依赖隐含不变量 + 死代码根检查）**：当前零泄漏（probe1 16 穿越变体实证），但 400 语义只覆盖字面 `..`/`\`；`%2e%2e` 家族靠「不解码 → ENOENT → 404」兜底，一旦未来任何层先解码即漏网；`abs.startsWith(join(__dirname,'..'))` 为不可达死代码。建议 `decodeURIComponent(urlPath)` 后判 `..`/`\`（一行，失败 → 400），并同步收紧 api-static 断言（400/404 双可断言 → 单 400）。
