## 发现的问题

- **[P1] `cov` 脚本缺 `--test` flag**：Node v24.18.0 中 `--experimental-test-coverage` 不再隐含测试模式，原写法在任何状态下都把字面 glob 当模块 require（`MODULE_NOT_FOUND`），脚本永远跑不起来。
  - **修复**：补 `--test` → `node --test --experimental-test-coverage --test-coverage-lines=90 --test-coverage-branches=85 --test-coverage-functions=90 --test-isolation=none tests/**/*.test.js`
  - **复测**：`npm run cov` → exit 0 + 覆盖率报告（0 用例时空匹配 vacuous 通过，与 test 一致；测试数断言由 P0-5 门禁第 7 项兜底）

## 传递给后续批次的环境事实（已实测，勿重复踩）

1. `node --test <目录>` 报 `ERR_UNSUPPORTED_DIR_IMPORT` —— **必须用 glob** `tests/**/*.test.js`（node 自行展开，cmd 下无需引号）。
2. 空匹配（无测试文件）→ exit 0 **静默通过** → P0-5 gate 第 7 项必须断言测试数 ≥ 1；P0-2 起测试目录非空后 `npm test` 变绿才有意义。
3. PowerShell 管道里 `$LASTEXITCODE` 可能是伪影（曾现 -1）——用 `cmd /c "... & echo RC=%ERRORLEVEL%"` 实测为准。
4. cov 阈值 flags（lines/branches/functions）在 v24.18.0 全部可用；阈值语义为**每文件**达标。
5. `demo:log` 的 `--log-level trace` 契约已写入 package.json，B11 实现 `scripts/demo.js` 时须兑现（README 已承诺等价 `DL_LOG_LEVEL=trace`）。
