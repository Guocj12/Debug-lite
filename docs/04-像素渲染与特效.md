# 像素渲染与霓虹特效系统

## 一、渲染架构

```
PixelRenderer.js (总调度)
    ├── PixelDrawer.js (底层绘图工具)
    ├── 角色渲染 (character sprites)
    ├── 特效渲染 (effect sprites)
    ├── 战场渲染 (battlefield)
    └── 霓虹后处理 (glow, scanline, particles)
```

---

## 二、核心渲染流程

```
每帧（requestAnimationFrame）:
  1. 清空 Canvas
  2. 绘制战场背景（网格线、地面像素）
  3. 绘制角色 shadow（地面阴影，降低 alpha）
  4. 绘制角色 glow layer（发光层：放大 + 模糊）
  5. 绘制角色 body（主体像素）
  6. 绘制角色 detail（武器、护盾等）
  7. 绘制特效粒子（飞行道具、爆发等）
  8. 霓虹后处理：扫描线 + 屏幕闪烁 + 色相偏移
  9. 绘制 UI 叠加层（血条等）
```

## 四、霓虹特效详解

### 4.1 角色发光（Glow）

实现方式：Canvas `shadowBlur`

```javascript
function drawWithNeonGlow(ctx, drawFn, glowColor, glowRadius = 15) {
    ctx.save();
    ctx.shadowColor = glowColor;
    ctx.shadowBlur = glowRadius;
    drawFn();  // 绘制角色主体
    ctx.restore();
    // 再正常绘制一遍（双层，发光+实体）
    drawFn();
}
```

### 4.2 呼吸发光（Pulse Glow）

```css
/* CSS 动画，作用于发光层的 alpha */
@keyframes neon-pulse {
    0%, 100% { opacity: 0.7; filter: blur(12px); }
    50%      { opacity: 1.0; filter: blur(18px); }
}
```

### 4.3 扫描线（Scanlines）

覆盖在整个画布上方的半透明条纹：

```css
/* 用 repeating-linear-gradient 实现 CRT 效果 */
.scanlines-overlay {
    position: absolute;
    top: 0; left: 0; width: 100%; height: 100%;
    background: repeating-linear-gradient(
        0deg,
        transparent,
        transparent 2px,
        rgba(0, 0, 0, 0.05) 2px,
        rgba(0, 0, 0, 0.05) 4px
    );
    pointer-events: none;
    z-index: 100;
}
```

### 4.4 像素粒子系统

攻击命中、技能释放时产生像素粒子：

```javascript
class PixelParticle {
    constructor(x, y, color, velocity, life) { ... }
    update() {
        this.x += this.vx;
        this.y += this.vy;
        this.life--;
        this.alpha = this.life / this.maxLife;
    }
    draw(ctx) {
        drawPixel(ctx, this.x, this.y, 4, this.color, this.alpha);
    }
}

class ParticleSystem {
    particles = [];
    emit(x, y, color, count, spreadRadius) { ... }
    updateAll() { ... }
    drawAll(ctx) { ... }
}
```

### 4.5 攻击特效类型

| 特效 | 实现 |
|------|------|
| **斩击弧线** | 绘制弧线上的像素点，快速消失 |
| **投射物** | 沿直线移动的像素块 + 拖尾残影 |
| **爆发** | 从中心向外扩散的像素环 |
| **雷电** | 随机折线像素，快速闪烁 |
| **地面震动** | Canvas 整体随机偏移 2-3px，持续 200ms |
| **护盾** | 角色周围的像素边框，脉冲发光 |
| **治疗** | 上升的十字形像素粒子 |

### 4.6 屏幕震动（Hit Shake）

```javascript
function applyScreenShake(ctx, intensity = 4, duration = 200) {
    const dx = (Math.random() - 0.5) * intensity * 2;
    const dy = (Math.random() - 0.5) * intensity * 2;
    ctx.translate(dx, dy);
    setTimeout(() => ctx.setTransform(1, 0, 0, 1, 0, 0), duration);
}
```

## 五、战场渲染

```
战场是一个 20 x 12 的像素网格
每个格子大小 = pixelScale（可配置，默认12px）

绘制内容：
- 深色背景 (#0a0a0a)
- 细网格线 (alpha 0.15)
- 可选的装饰像素（地面纹理，从 pixelSprites.json battlefield 读取）
- 双方角色（根据 position 坐标定位）
```

### 坐标系统

```
(0,0) ────────── (19,0)
 │                   │
 │    战场 20x12     │
 │                   │
(0,11) ───────── (19,11)

角色 position: { x: 0-19, y: 0-11 }
渲染坐标: canvasX = x * pixelSize, canvasY = y * pixelSize
```

## 六、动画时间线（BattleAnimator.js）

战斗阶段的动画是逐步播放的：

```javascript
class BattleAnimator {
    constructor(actionsData) {
        this.steps = actionsData;  // 服务端发来的全部步骤
        this.currentStep = 0;
        this.stepDelay = 600;      // 每步间隔 ms
    }

    playStep() {
        const step = this.steps[this.currentStep];
        
        // 1. 移动角色（平滑过渡 vs 瞬移，瞬移更好看）
        // 2. 显示行动名称（如"火焰弹！"）
        // 3. 播放对应特效动画
        // 4. 更新血条
        // 5. 等待 stepDelay 后播放下一步
        
        this.currentStep++;
    }

    // 关键：动画播完当前步骤后才请求下一步数据
    // 用 setTimeout 控制节奏
}
```

## 七、角色形状渲染规则

### humanoid（人形）
严格按照 `pixels` 字符串数组逐格绘制，每个字符对应一个颜色

### circle（圆形）
以 pixels 数组大小为边界，内部像素按圆形公式 `(x-cx)² + (y-cy)² ≤ r²` 判定是否填充

### triangle（三角形）
以 pixels 数组大小为边界，内部像素按三角形顶点范围填充

### square（正方形）
直接用 pixels 数组绘制，圆角可选

## 八、性能注意事项

1. **双 Canvas 架构**：
   - 背景 Canvas（静态，低频更新）
   - 前景 Canvas（角色+特效，60fps）
   
2. **粒子池**：预创建粒子对象，复用而非 new

3. **离屏 Canvas**：发光层先在离屏 Canvas 绘制 → 模糊 → 再合成到主 Canvas

4. **requestAnimationFrame**：用 rAF 而非 setInterval
