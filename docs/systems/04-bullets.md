# 弹幕系统 详细设计

> 所属：Debug-Lite v3　本文档精确到代码逻辑（自然语言，不写代码）。与 `../v3-design.md` 冲突时以本文档为准。

## 1. 职责

- 弹幕生成、**当 tick 内飞完全射程**、命中与互撞解算。
- 等级碰撞（高穿低 / 同级双消 / 低被高消）。
- 输出 **1px 精度**的命中位置与碰撞位置，供前端绘制与回放。

## 2. 依赖

- `field.js`：px 坐标、格↔px 换算、边界与基地区域。
- `battle-config.json`：`cellPx`、`fieldPx`、精度等。
- 命中结算回调（引擎提供）。

## 3. 数据结构

```jsonc
{
  "uid": "b_...",
  "owner": "p1",                 // p1 | p2
  "skillId": "skill2",
  "type": "straight",            // melee | straight | vertical
  "level": 2,                    // 1 最高，4 最低
  "dir": 1,                      // 1 右，-1 左
  "x0": 224,                     // 生成位置（px，1px 精度）
  "len": 512,                    // 射程长度 = range × cellPx
  "v": 512,                      // 本 tick 位移量（px/tick）= range×cellPx；melee/vertical 为 0
  "hitSet": [],                  // 已命中的目标（保证"同一弹幕对同一目标只结算一次"）
  "payload": { "multiplier": 1.3, "falloff": 0, "affixes": [] }
}
```

**已删除字段**：`pathThisTick`、`traveled`、`speed`、`maxRange`、`alive`（见 D-21/D-31）。弹幕只存在于**生成它的那一个 tick**（D-20）。

## 4. 核心流程（代码逻辑）

### 4.1 生成 `spawn(skill, caster)`

| 类型 | 生成方式 |
|---|---|
| `melee` | 按 `range` 相对**朝向**算出覆盖格集合；**每格生成一枚 0 速弹幕**（D-22/D-26），`x0` = 该格中心 px，`v = 0` |
| `straight` | 按 `bulletCount` 生成 N 枚；`x0` = **释放者所在格的中心**（D-22，不在邻格），`dir` = 朝向，`v = range × cellPx` |
| `vertical` | 落点 = `clampX(caster.x + dir × range × cellPx)`；按 `area` 相对朝向算出覆盖格集合；**每格一枚 0 速弹幕**，`x0` = 该格中心 |

- 生成顺序即**结算顺序**（D-27），必须记录单调递增序号。
- 因角色永不重叠（D-06），平射的生成格内不会有敌人，故**不需要"生成格命中"特判**（D-30）。

### 4.2 命中判定（**连续方程求交**，D-23）

以 tick 归一化时间 `t ∈ [0,1]`，角色本 tick 从 `x_before` 匀速移动到 `x_after`：

```
角色： x_c(t) = x_before + (x_after - x_before) × t
弹幕： x_b(t) = x0 + dir × v × t
解    x_b(t) = x_c(t)  →  得 t*
```
- 若存在 `t* ∈ (0, 1]` 且该时刻弹幕未超出射程 → **命中**；命中位置 = `x_b(t*)`。
- 结果**四舍五入到 1px（= 1/64 格）**后输出（D-02/D-08/S18）。
- **AOE（`v = 0`）**：不参与上面的求交，改为判定 **t = 1（即位移后）** 时目标中心是否落在其覆盖 px 区间内（**D-24：走出范围即可躲开**）。
- **命中次数**：AOE 对每个目标最多一次；**平射可多次命中同一目标**（多发各算一次，D-25）。同一枚弹幕对同一目标只结算一次（`hitSet`，`T-BT-10`）。

### 4.3 弹幕互撞（D-28）

对任意两条**不同归属**的弹幕，同样解连续方程求"同一时刻位置相等"：
- 求解区间为 **`t ∈ [0, 1]`（含 `t = 0`，D-32 / G1）**：当敌人在自己所在格开火、而某枚弹幕恰好覆盖该格时，二者在 `t = 0` 位置相同 → **立即互相拦截**，不允许"飞到下一格才拦下"；
- 存在公共 `t*` 且位置相等（1/64 格精度内）→ **碰撞**，碰撞位置 = 该点；
- **等级比较**：数字小者等级高。
  - 高 vs 低 → **低者移除，高者继续**飞完全射程并参与后续命中判定；
  - 同级 → **双方同时移除**（双消），此后都不再参与任何判定。
- 不允许用"轨迹区间重叠"近似（D-08/SPEC-A）。

### 4.4 遍历与递归（D-27）

```
按弹幕生成先后顺序遍历：
  对当前弹幕 B：
    与所有仍存活的敌方弹幕逐个做 4.3 的碰撞判定
    若发生碰撞 → 立即处理（移除败者），并把"胜者"继续留在候选集
    B 仍存活 → 做 4.2 的命中判定
```
- 语义上是**递归**的：任何一次移除都可能让原本会被抵消的弹幕存活下来，因此判定必须基于"当前仍存活集合"，而非一次性的静态快照。
- 每 tick 结束时**存活弹幕数必须为 0**（`T-BT-19`）。

## 5. 边界与异常

- **`fullDodgeDuring` 角色不参与判定（D-72）**：处于该状态的角色在本 tick 的弹幕命中与抵消判定中**被完全忽略**（弹幕既不因它命中、也不因它被消耗，径直穿过）。
- 位置比较统一量化到 1px，避免浮点误差导致同 seed 结果漂移（`T-BT-17`）。
- 弹幕**不伤害自己**（D-30）、**不对基地造成任何伤害**（D-60）。
- 目标已死亡（`hp ≤ 0`）时不再结算伤害，但**碰撞与抵消照常**（弹幕仍会被打掉）。
- 射程尽头**含终点**（D-30）：`t*` 恰好在射程末端时仍判定命中。

## 6. 对外接口（B7 落地名）

- `spawnBullets(battle, act)`：技能系统调用（释放指令 → 战场弹幕，补 uid/order/hitSet，记 spawn 事件）。
- `resolveBullets(battle, ctx)`：引擎每 tick 步骤 8 调用一次，返回 {spawns, collides, hits, expires}（bullet.spawn/collide/hit/expire 事件）。
- `solveIntersection(x1, v1, x2, v2, tMax, tMin)`：连续方程求解原语（角色-弹幕、弹幕-弹幕共用；闭区间 [tMin, tMax]）。
- `bulletBattle(a, b)`：等级比较矩阵（'b1'/'b2'/'both'/'none'）。
- `bulletsOnField(battle)`：场上存活弹幕数（tick 末恒 0，T-BT-19）。

## 7. 测试要点（对应 `docs/tasks.md` §3.2）

| 编号 | 要点 |
|---|---|
| T-BU-1 | 等级碰撞矩阵：高穿低（低者消失、高者继续）、同级双消、低被高消 |
| T-BU-2 | 三种结束：命中 / 到达射程尽头 / 无命中自然结束 |
| T-BU-3 | 近战每格一枚独立弹幕；每格各自参与等级判定 |
| T-BU-4 | 同刻生成顺序确定（生成序号决定结算顺序） |
| T-BU-5 | 连续方程：相向必中；同向追及（弹幕更快才命中）；擦肩而过不命中 |
| T-BU-6 | AOE 按**位移后**位置判定（走出范围即无事） |
| T-BU-7 | `falloff` 衰减数值正确（每向外一格减伤%，默认 0） |
| T-BU-8 | 弹幕不跨 tick：tick 末存活弹幕数恒为 0 |
