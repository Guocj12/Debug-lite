# 弹幕系统 详细设计

> 所属：Debug-Lite v3　本文档精确到代码逻辑（自然语言，不写代码）。与 `../v3-design.md` 冲突时以本文档为准。

## 1. 职责

- 弹幕的生成、每 tick 位置推进。
- 弹幕等级碰撞（高穿低、同级抵消、低被高抵消）。
- 命中与消失判定。

## 2. 依赖

- `field.js`（坐标越界、格子判定）。
- 命中结算回调（由引擎提供）。

## 3. 数据结构

- 弹幕：`uid`、`owner`（p1/p2）、`skillId`、`level`（1 最高，4 最低）、`type`（melee/straight/vertical）、`dir`、`speed`（格/tick，melee 为 0）、`x`（当前位置，可小数）、`pathThisTick[]`（本 tick 将经过的格，按近到远排序）、`traveled`、`maxRange`、`payload`（倍率/词条）、`alive`。

## 4. 核心流程（代码逻辑）

### 4.1 生成 `spawn(skill, caster)`

1. 由技能系统给出弹幕参数（等级、速度、射程、方向、数量）。
2. 计算初始 `x`（近战=角色所在格，平射=角色朝向的邻格，垂直=落点格）。
3. 计算 `pathThisTick`：
   - melee：`pathThisTick` = 覆盖格集合，速度 0。
   - straight：从当前格起、沿方向取 `speed` 个相邻格。
   - vertical：落点格及 `area` 范围内的格。
4. `alive = true`，`traveled = 0`。

### 4.2 推进 `advance(bullet)`

1. 若 `type === melee`：本 tick 结算覆盖格后立即标记 `alive = false`（下一 tick 消失）。
2. 否则：`x` 沿方向推进 `speed` 格；`traveled += speed`；重算 `pathThisTick`。
3. `traveled >= maxRange` → 标记射程耗尽，`alive = false`。

### 4.3 逐格判定 `resolveTick(bullets, players, bases)`

对所有存活弹幕，按「经过的格从近到远」顺序处理每格，每格内依次判断：

1. **阻挡（弹幕碰撞）**：该格是否与敌方弹幕相遇。
   - 高等级穿过低等级 → 低等级弹幕消失。
   - 同级 → 双方消失。
   - 低等级被高等级抵消 → 低等级消失。
2. **命中**：该格是否有敌方角色。
   - 有 → 结算 `payload`（伤害 + 词条）到目标，本弹幕消失。
   - 平射弹幕命中时把「弹幕来向/飞行方向」传给伤害管线，用于背击判定；垂直弹幕不传（永不触发背击）。
3. **射程**：已到达 `maxRange` → 本弹幕消失。

- 同一格内三者同时满足时，按「阻挡 → 命中 → 射程」的优先级，先触发者生效（本弹幕按该结果处理）。
- 弹幕飞出地图（越界）→ 直接消失。

### 4.4 近战弹幕

- 生成时即对 `pathThisTick` 每格独立判定命中，本 tick 结算完成后立即消失（下一 tick 不再存在）。
- 近战弹幕之间也参与等级碰撞（同级抵消等），规则同 4.3。

## 5. 边界与异常

- 小数坐标与格子：用「经过的整数格」列表做碰撞与命中，位置保留小数用于渲染。
- 同格多弹幕：按固定遍历顺序（先 p1 后 p2，先早生成后晚生成）处理，保证确定性。
- 双方弹幕同格同级同时消失时，不再参与后续命中。

## 6. 对外接口

- `spawn`：技能系统调用。
- `resolveTick`：引擎每 tick 调用，返回命中/抵消事件列表。

## 7. 测试要点

- 等级碰撞矩阵：高穿低、同级抵消、低被高抵消。
- 命中敌人消失、射程耗尽消失、飞出地图消失。
- 近战弹幕本 tick 立即消失。
- 同格多弹幕的确定性与顺序。
