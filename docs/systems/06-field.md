# 场地系统 详细设计

> 所属：Debug-Lite v3　本文档精确到代码逻辑（自然语言，不写代码）。与 `../v3-design.md` 冲突时以本文档为准。

## 1. 职责

- 16 格横版场地：坐标 0~15。
- 两侧边界外的基地。
- 初始位置与朝向。
- 基地受击判定。

## 2. 依赖

- 无（纯坐标与配置）。

## 3. 数据结构

- 场地：`width=16`、`bases{p1,p2}`、`startX{p1,p2}`、`startFacing{p1,p2}`。
- 基地：`owner`、`x`（边界外侧 0 / 15）、`hp`、`maxHp`、`def`。

## 4. 核心流程（代码逻辑）

### 4.1 坐标 clamp

1. 角色坐标限制在 [0,15]，不可越界。
2. 位移/击退/拉近结果都经 clamp 后再写回。

### 4.2 初始位置

1. P1 初始 `x=3`、`facing=1`（朝右）；P2 初始 `x=12`、`facing=-1`（朝左）。
2. 基地：P1 基地在格 0 左侧、P2 基地在格 15 右侧。

### 4.3 基地受击判定

- 角色攻击基地的条件：攻击方向朝向敌方基地、且射程/覆盖范围触及边界外。
  - 近战/位移：角色位于边界格（P1 在 15 且朝右、P2 在 0 且朝左）时，朝基地方向的攻击判定命中基地。
  - 平射/垂直：弹幕沿朝向到达地图边缘后继续判定命中基地。
- 命中基地 → 按伤害管线对基地扣血（基地有 def 减伤）。

### 4.4 朝向与方向

- 朝向为正方向（+1 右、-1 左）时，技能/弹幕作用方向跟随朝向。
- 转向行动翻转朝向。

## 5. 边界与异常

- 角色永不在基地格（基地在边界外，角色只到 0 或 15）。
- 击退/拉近不可把角色推出地图。

## 6. 对外接口

- `clamp(x)`：各系统坐标归一。
- `isBaseHit(actor, dir)`：引擎判断基地受击。

## 7. 测试要点

- 初始位置 x=3 / x=12、朝向正确。
- clamp 上下界。
- 基地受击条件（方向、边界格）。
- 击退不越界。
