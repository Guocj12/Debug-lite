# 场地系统 详细设计

> 所属：Debug-Lite v3　本文档精确到代码逻辑（自然语言，不写代码）。与 `../v3-design.md` 冲突时以本文档为准。

## 1. 职责

- 横版场地的**连续坐标**定义与边界约束。
- 两侧基地的位置与受击判定。
- 初始位置与朝向。
- 格 ↔ px 换算（供技能范围、AOE、渲染共用）。

## 2. 依赖

- `battle-config.json`：`cellPx`、`fieldPx`、`actorHalfPx`、`baseDef`。
- 无其他模块依赖（纯坐标与配置）。

## 3. 数据结构

```jsonc
{
  "cellPx": 64,          // 每格像素宽
  "cells": 16,
  "fieldPx": 1024,       // 16 × 64
  "actorHalfPx": 32,     // 角色半径（体积 = 1 格）
  "minGapPx": 64,        // 两角色中心距下限（永不重叠）
  "startX": { "p1": 224, "p2": 800 },        // 格 3 / 格 12 的格中心
  "startFacing": { "p1": 1, "p2": -1 },
  "base": { "p1": { "range": [-64, 0], "hp": 100, "maxHp": 100, "def": 64 },
            "p2": { "range": [1024, 1088], "hp": 100, "maxHp": 100, "def": 64 } }
}
```

## 4. 核心流程（代码逻辑）

### 4.1 坐标与边界

1. 场地 `x ∈ [0, 1024]`，**精度 1px（= 1/64 格）**。
2. 格 `c` 占 `[64c, 64(c+1))`；**角色位置取其格中心**，即 `x_center(c) = 64c + 32`。
3. 角色中心 `clampX(x)` 到 `[32, 992]`（格 0 ~ 格 15 的中心范围）——角色**不会**进入基地区域。
4. `cellOf(x) = floor(x / 64)`（clamp 到 `[0,15]`）。
5. `cellRange(lo, hi, facing, originX)`：按**相对朝向**把区间 `[lo,hi]` 映射为格集合（`c` 的偏移量为 `facing × c`），越界格丢弃。近战/AOE 的覆盖格由此得出。

### 4.2 初始状态

- P1：`x = 224`（格 3 中心）、`facing = +1`（朝右）。
- P2：`x = 800`（格 12 中心）、`facing = −1`（朝左）。
- 基地：P1 在 `[-64, 0)`、P2 在 `(1024, 1088]`。

### 4.3 基地区域与受击（**重大变更**）

> ⚠️ **弹幕不对基地造成任何伤害**（D-60）。

- **唯一的基地伤害方式**：角色**面向基地**且**向基地方向移动**（D-61）：
  1. 判定条件：角色朝基地方向的移动/位移意图的目标位置会越过 `[32, 992]` 边界（即意图 `x ≤ 32` 且 `facing = -1`（P1 打左基地不可能，实际为 `x ≥ 992` 且 `facing = +1` 打 P2 基地）），或已在边界格仍继续向基地移动；
  2. 结果：角色**停在原地**（位置不变，不越界）；
  3. 同时对基地造成 `atk × 0.8` 的伤害，走基地 `def = 64` 的减伤公式（见 `07-engine`）；
  4. 基地**不反击**（角色不受伤）。
- **位移技能撞基地**同理：停在原地 + 造成伤害，`dealDamage` 语义对基地生效。

### 4.4 朝向与方向

- 朝向 `facing = +1`（右）/ `-1`（左）；`turn` 行动翻转。
- 技能/弹幕方向跟随朝向；**移动方向与朝向相互独立**（可以背对敌人后退）。
- 朝向同时用于**背击判定**（见 `07-engine`，用**位移后**的朝向，D-50）。

## 5. 边界与异常

- 任何位移结果（移动/位移/击退/拉近）都经 `clampX` 后再写回。
- 击退/拉近**不得使两角色中心距 < 64px**（D-06）：若目标位置会重叠，停在相距 64px 处。
- 角色与基地**永不重叠**（基地在 `[32,992]` 之外）。
- 浮点结果统一量化到 1px。

## 6. 对外接口

- `FIELD_PX` / `CELL_PX` / `ACTOR_HALF` / `START_X` / `START_FACING`
- `clampX(x)` / `cellOf(x)` / `xCenter(c)` / `cellRange(lo, hi, facing, originX)`
- `baseOf(owner)` / `touchesBase(actor, targetX, dir)`（撞基地判定）
