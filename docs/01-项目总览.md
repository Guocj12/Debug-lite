# 🎮 霓虹像素双人对战游戏 — 项目总览

## 一句话描述

基于浏览器的霓虹像素风双人对战游戏。通过房间号联机，采用"预设行动队列 → 自动战斗"的独特机制。纯点击操作，兼容手机与电脑。

---

## 技术栈

| 层 | 技术 | 说明 |
|----|------|------|
| 前端 | 原生 HTML/CSS/JS + Canvas | 无框架，零依赖（除 socket.io-client CDN） |
| 后端 | Node.js + Express + Socket.IO | 轻量实时通信 |
| 数据 | JSON 文件 | 角色、技能、像素画全部 JSON 配置 |
| 部署 | pm2 + Nginx | 守护进程 + 反向代理 |

---

## 核心玩法

```
┌──────────┐     ┌──────────────┐     ┌──────────────┐
│  大厅匹配  │ ──→ │ 准备阶段 60s  │ ──→ │ 自动战斗阶段  │
│ 创建/加入  │     │ 编辑行动队列  │     │ 双方队列同时  │
│   房间     │     │ 可任意修改    │     │ 按序执行      │
└──────────┘     └──────────────┘     └──────┬───────┘
                     ↑                       │
                     │        ┌──────────────┘
                     │        ↓
                     │  ┌───────────┐
                     └──│ 一方死亡？ │
                        │ 否→回准备  │
                        └───────────┘
                            │是
                            ↓
                      ┌───────────┐
                      │  游戏结束  │
                      └───────────┘
```

每回合流程：
1. **准备阶段**（60秒）：双方各自编辑行动队列，如 `[右移, 防御, 攻击, 火球术, 左移]`
2. **战斗阶段**：双方队列同时执行，播放战斗动画
3. 若无人死亡 → 回准备阶段
4. 若一方死亡 → 游戏结束

## 设计原则

1. **纯前端渲染**：所有画面用 Canvas 绘制像素，无任何图片素材
2. **JSON 驱动**：角色外观、技能效果、动画帧都由 JSON 配置
3. **纯点击操作**：不依赖键盘，手机电脑通用
4. **服务端权威**：战斗计算在服务端，客户端只负责渲染和发送指令
5. **单页应用**：只有一个 HTML 页面，不同阶段切换显示不同 UI 面板
