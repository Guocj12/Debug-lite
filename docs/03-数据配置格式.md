# 数据配置格式

所有游戏内容通过 JSON 文件配置。服务端和客户端各存一份（开发时手动同步，或服务端启动时加载后通过 API 传给客户端）。

### 技能字段说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `id` | string | ✅ | 唯一标识，英文 |
| `name` | string | ✅ | 显示名称 |
| `type` | string | ✅ | attack/defense/buff/debuff/heal/movement |
| `icon` | string | ✅ | emoji 图标 |
| `description` | string | ✅ | 说明文本，`{damage}` 等会自动替换 |
| `damage` | number | ❌ | 基础伤害值 |
| `healAmount` | number | ❌ | 治疗量（heal 类型专用） |
| `dotDamage` | number | ❌ | 每回合持续伤害 |
| `range` | number | ❌ | 作用距离（格子数），默认1 |
| `distance` | number | ❌ | 移动距离（movement 类型专用） |
| `duration` | number | ❌ | 效果持续回合数（buff/debuff） |
| `cooldown` | number | ✅ | 冷却回合数 |
| `selfDamage` | number | ❌ | 对自身的反噬伤害 |
| `knockback` | number | ❌ | 击退格数 |
| `lifeSteal` | number | ❌ | 吸血比例 (0-1) |
| `ignoreDefense` | boolean | ❌ | 是否无视防御 |
| `effects` | array | ❌ | 附加效果列表 |
| `pixelAnimation` | string | ✅ | 对应的像素动画名称 |
| `neonColor` | string | ✅ | 霓虹光效颜色（hex） |
| `soundEffect` | string | ❌ | 音效名称（暂不实现） |

### 效果类型（effects 数组中的 type）

| type | 说明 | 额外字段 |
|------|------|----------|
| `stun` | 眩晕（跳过行动） | duration |
| `poison` | 中毒 | damagePerTurn, duration |
| `attack_up` | 攻击力提升 | value(百分比), duration |
| `defense_up` | 防御力提升 | value(百分比), duration |
| `attack_down` | 攻击力降低 | value(百分比), duration |
| `defense_down` | 防御力降低 | value(百分比), duration |
| `speed_up` | 速度提升 | value(百分比), duration |
| `speed_down` | 速度降低 | value(百分比), duration |
| `damage_reduction` | 伤害减免 | value(百分比), duration |
| `burn` | 灼烧 | damagePerTurn, duration |
| `freeze` | 冰冻 | duration |
| `bleed` | 流血 | damagePerTurn, duration |

### 像素字符约定

| 字符 | 含义 | 渲染颜色 |
|------|------|----------|
| `X` | 主体像素 | 角色的 `bodyColor` |
| `W` | 武器/白色像素 | `#ffffff`（武器） |
| `I` | 内部像素 | `innerColor` |
| `F` | 面部像素 | `faceColor` |
| `S` | 护盾像素 | 护盾特效色 |
| `G` | 发光像素 | 角色的 `glowColor` |
| `.` | 透明 | 不渲染 |

### 渲染规则

1. **基础形状（humanoid）**：按 `pixels` 数组逐格绘制
2. **形状覆盖（circle/triangle/square）**：`shapeOverride` 不为空时，按像素数组的边界自动用算法平滑成对应形状
3. **帧动画**：`idle` → `move_frame1` → `move_frame2` → `idle` 循环
4. **特效动画**：effects 中的特效有独立的速度（ms）、轨迹、消失方式

## 四、自定义技能（预留框架）

```json
{
  "customSkills": {
    "enabled": false,
    "editorUrl": "/skill-editor",
    "validation": {
      "maxDamage": 50,
      "maxHeal": 30,
      "maxRange": 5,
      "maxDuration": 5,
      "minCooldown": 2,
      "maxCooldown": 10
    }
  }
}
```

自定义技能编辑器是留空的 UI 页面，后续实现。框架层面技能系统已通过 `skills.json` 的 `type` + `effects` 组合支持任意技能效果。
