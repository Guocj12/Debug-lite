## 1. 等价点数（EP）模型（已落地）

**角色战力**（引擎伤害公式解析推导，乘性可分）：

```
承伤系数  dt(D) = defK / (D + defK)
战力      P = A × H × (D + defK)
```

| 属性 | 每点边际战力 | 换算 |
|---|---|---|
| atk | `1/A = 6.667%` | **1 atk ≡ 6.33 hp ≡ 3.20 def** |
| hp | `1/H = 1.053%` | — |
| def | `1/(D+defK) = 2.083%` | def 的因子作用于 `(D+defK)`，不作用于 `def` |
| sp / mp | 见 §6.1 资源折算 | 与技能消耗同源 |

**等贡献判据**：品质系数 = 1.0（标准值）时，同品质的**模板之间**、**插件之间**战力相等；品质浮动是刻意的方差来源。
**每点战力旋钮** `p = 0.085`（角色插件每 1 点 = +8.5% 标准战力）。

## 6. 技能系统（已落地）

### 6.1 技能配平模型（效率恒定）

**基准**（B0，`hit` 为一次满命中普攻的期望伤害）：

```
hit = atk × baseHitMul × (1 − def/(def+defK)) = 15 × 0.8 × (1 − 8/48) = 10.0
位置命中  p_pos：近战 0.6 / 平射 0.8 / 定点 0.8 / 位移 0.5
覆盖价值  covered：近战 = 覆盖格数(hi−lo+1)；平射 = 弹幕数；定点 = Σ max(0, 1−衰减×|偏移|)（**线性**，与 `core/bullets.js:160` 同一口径）；位移 = 距离（造成伤害时，否则 0）
暴击因子  crit = 1 + 暴击率 × (1 + 暴击倍率加成)
期望伤害  D = hit × 倍率 × covered × p_pos × crit
```

> **弹幕等级与伤害完全独立（2026-09-28 用户裁定，D-175）**：等级（1 最高 / 4 最低）**只决定弹幕互撞优先级**，
> **不进伤害公式**（旧口径的 `lf(L) = 1 + 0.05×(L−2)` 作废）。技能伤害只由 `multiplier` 承载（受通用/专属插件影响）。

**等效收益（加项）**：

```
眩晕      剩余 tick × 10            （1 tick = hit）
击退/拉近 格数 × 3                  （1 格 = 0.3 × hit）
射程      (射程 − 基准射程) × 1      （1 格 = 0.1 × hit）
位移      (距离 − 1) × 3
全程闪避  10
穿敌      3
自身增益  Δ / 分母 × 10 × tick      （分母：atk 15 / def 48 / sp 73 / mp 62）
敌方减防  |Δdef| / 48 × 10 × tick
敌方持续  倍率 × hit × tick            （D-175：持续伤害自带**倍率**，每 tick 按施法者 atk 走常规伤害公式）
```

**替代行动（减项，设计常数，用户 2026-09-28 确认维持）**：近战 `9.0` / 平射 `6.0` / 定点 `6.0` / 位移 `0`。
（含义 =「不施放技能时，同样一次行动能拿到的期望收益」：平射/定点的一次普攻 = `hit × p_pos 0.6`；近战的普攻是**多格弧**，其期望值按 `0.9 × hit` 计；位移技不替代攻击 → 0。）

```
优势   adv = D + Σ等效收益 − 替代行动
代价   cost = sp + mp + 4 × CD        （cdUnit = B0 每 tick 资源收入 = mp 2 + sp 2 = 4）
配平   η = adv / cost ≈ 0.40（全形态一致，实测 0.39~0.41）
```

**冷却档位**：`adv <5 → CD1；<9 → 2；<14 → 3；<20 → 4；<26 → 5；<32 → 6；≥32 → 7`（上限 8）。
**资源拆分**：`资源 = cost − 4×CD`；近战/位移 → 全 SP；平射 → 先取整 SP = round(资源×30%)、**MP 吃掉余数**（D-175：两维各自独立取整会让 Σ维度 > cost，使 η 掉出 0.40±0.02）；定点 → 全 MP。
**上限**：单技能 SP ≤35、MP ≤35、CD ≤8；**资源超上限 → CD 上调一档后再拆**（当前 20 条形态均未触发）。
**基准战斗**：T = 20 tick；三个技能的期望合计释放 **8~12 次**（约每 2 tick 一次）。
**品质浮动**：技能只有 `multiplier`（与专属插件的伤害类数值）随品质浮动。
**复算**：`node .audit/content-design.js` 逐条复算本模型的 D/adv/η/sp/mp/CD 并与 `server/data/*.json` 比对（漂移即 exit 1）。

### 6.2 技能插槽与专属插件

- 技能物品 = **1 个专属槽（固定）+ N 个通用槽**（N 按品质：0-1 / 0-2 / 1-3 / 2-4 / 3-4）。
- **每个技能至多 1 个专属插件**；专属插件**按技能类型绑定**（`forTypes`），装上即改造成该形态（技能显示名 = 专属插件名）。
- 技能不再有 `basic`/`special` 槽分型；**通用槽接受任意通用插件**。
- 专属插件**同池掉落**，有品质与品质浮动（覆盖型字段不浮动）。
- **动画与命名**：专属插件携带 `name` / `animKey` / `sfxKey`，写入内容表并**暴露到物品视图与回放帧**（帧的 action 携带技能名与动画键）；占位素材见 `assets/animations.json` 的 `animations.skill` / `sounds.skill`（20 条，T9 已补齐）。
- **starter 发放规则**（用户 2026-09-28 裁定）：新手套装**保证 1 个专属 + 1 个通用**技能插件（`server/starter.js` 两轮确定性选择 + 重掷到至少 1 个技能有通用槽）。
- 专属插件的效果在数据表**声明式覆盖**：`exclusive: { forTypes, overrides{...}, hitEffects[], castEffects[], cost, cooldown }`。
